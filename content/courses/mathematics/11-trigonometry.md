# Trigonometry

Trigonometry studies the relationships between the angles and sides of triangles. The A-Level paper extends GCSE trigonometry to radians, exact values, and trigonometric equations.

### What you must know

- **Radians:** An angle of $1$ radian subtends an arc of length equal to the radius. $\pi$ radians $= 180^\circ$. To convert: $x^\circ = \frac{\pi}{180}x$ radians.
- **Sine, Cosine, Tangent:** In a right-angled triangle, $\sin \theta = \frac{\text{opposite}}{\text{hypotenuse}}$, $\cos \theta = \frac{\text{adjacent}}{\text{hypotenuse}}$, $\tan \theta = \frac{\text{opposite}}{\text{adjacent}}$.
- **Exact values:** $\sin 30^\circ = \frac{1}{2}$, $\cos 30^\circ = \frac{\sqrt{3}}{2}$, $\sin 45^\circ = \frac{\sqrt{2}}{2}$, $\cos 45^\circ = \frac{\sqrt{2}}{2}$, $\sin 60^\circ = \frac{\sqrt{3}}{2}$, $\cos 60^\circ = \frac{1}{2}$.
- **Pythagorean identity:** $\sin^2\theta + \cos^2\theta = 1$.
- **Trigonometric equations:** Solve using exact values, calculators, and trigonometric identities.

### Worked example

**Solve $\sin \theta = \frac{1}{2}$ for $0^\circ \leq \theta \leq 360^\circ$.**

Step 1: Find the basic angle: $\sin^{-1}(\frac{1}{2}) = 30^\circ$.

Step 2: Sine is positive in quadrants I and II. The solutions are $\theta = 30^\circ$ and $\theta = 180^\circ - 30^\circ = 150^\circ$.

Step 3: $\theta = 30^\circ, 150^\circ$.

### Worked example 2

**Solve $\cos \theta = -\frac{1}{2}$ for $0 \leq \theta \leq 2\pi$ radians.**

Step 1: Find the basic angle in radians: $\cos^{-1}(-\frac{1}{2}) = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$.

Step 2: Cosine is negative in quadrants II and III. The solutions are $\theta = \frac{2\pi}{3}$ and $\theta = \pi + \frac{\pi}{3} = \frac{4\pi}{3}$.

Step 3: $\theta = \frac{2\pi}{3}, \frac{4\pi}{3}$.

### Common mistakes to avoid

- Using degrees when the problem requires radians (or vice versa).
- Forgetting that trigonometric equations may have infinitely many solutions; state the given interval.
- Confusing $\sin^2\theta + \cos^2\theta = 1$ with $\sin^2\theta - \cos^2\theta = 1$.

### Practice questions

1. Convert $60^\circ$ to radians.
2. Find $\sin 30^\circ$ and $\cos 30^\circ$.
3. Solve $\tan \theta = 1$ for $0^\circ \leq \theta \leq 360^\circ$.
4. Convert $\frac{\pi}{4}$ radians to degrees.

### Answers

1. $\frac{\pi}{3}$.
2. $\sin 30^\circ = \frac{1}{2}$, $\cos 30^\circ = \frac{\sqrt{3}}{2}$.
3. $\theta = 45^\circ, 225^\circ$.
4. $45^\circ$.
