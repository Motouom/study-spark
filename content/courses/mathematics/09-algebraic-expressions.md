# Algebraic Expressions and Functions

Algebraic expressions and functions form the foundation of A-Level Mathematics. The GCE paper tests manipulation of expressions, solving equations, and understanding function notation. Master these core skills early.

### What you must know

- **Simplifying expressions:** Collect like terms, expand brackets, factorise common factors. Example: $2x^2 + 3x - x^2 + 4 = x^2 + 3x + 4$.
- **Factorising:** Look for common factors, difference of squares $a^2 - b^2 = (a-b)(a+b)$, and quadratic trinomials $x^2 + bx + c$. Example: $x^2 - 5x + 6 = (x-2)(x-3)$.
- **Functions:** A function $f$ maps each input $x$ to exactly one output $f(x)$. The domain is the set of possible inputs, the range is the set of resulting outputs.
- **Composite functions:** $f(g(x))$ means substitute $g(x)$ into $f(x)$. Example: $f(x) = x^2, g(x) = x+3 \Rightarrow f(g(x)) = (x+3)^2$.
- **Inverse functions:** $f^{-1}(x)$ undoes $f(x)$. If $f(x) = 2x+3$, then $f^{-1}(x) = \frac{x-3}{2}$.
- **Transformations of graphs:** $y = f(x) + a$ shifts graph vertically by $a$, $y = f(x+a)$ shifts horizontally by $-a$, $y = kf(x)$ stretches vertically by $k$, $y = f(kx)$ stretches horizontally by $1/k$.

### Worked example

**Simplify $\frac{x^2 - 9}{x + 3}$.**

Step 1: Factorise the numerator: $x^2 - 9 = (x-3)(x+3)$.

Step 2: Cancel the common factor $(x+3)$: $\frac{(x-3)(x+3)}{x+3} = x-3$.

Step 3: Simplified expression: $x-3$ (for $x \neq -3$).

### Worked example 2

**Given $f(x) = 3x - 5$ and $g(x) = x^2 + 1$, find $f(g(2))$.**

Step 1: Find $g(2)$: $g(2) = 2^2 + 1 = 5$.

Step 2: Substitute into $f$: $f(5) = 3(5) - 5 = 10$.

Step 3: $f(g(2)) = 10$.

### Common mistakes to avoid

- Forgetting to specify the domain when simplifying rational expressions.
- Confusing $f(g(x))$ with $g(f(x))$ (order matters).
- Forgetting that $f^{-1}(x)$ exists only if $f$ is one-to-one.

### Practice questions

1. Factorise $x^2 - 7x + 12$.
2. Given $f(x) = 2x + 1$, find $f^{-1}(x)$.
3. If $f(x) = x + 2$ and $g(x) = x^2$, find $f(g(x))$.
4. Describe the transformation $y = f(x) - 3$.

### Answers

1. $(x-3)(x-4)$.
2. $f^{-1}(x) = \frac{x-1}{2}$.
3. $f(g(x)) = x^2 + 2$.
4. The graph shifts down by 3 units.
