## CORRIGÉ TYPE

**Q1.** Schéma : membrane, cytoplasme, noyau, mitochondries, vacuoles petites.

**Q2.** Végétale : paroi cellulosique, chloroplastes, grande vacuole. Animale : pas de paroi, pas de chloroplastes, petites vacuoles.

**Q3.** Membrane : échanges sélectifs. Noyau : ADN, commande. Mitochondries : respiration, ATP. Chloroplastes : photosynthèse.

**Q4.** Diffusion : mouvement particules gradient concentration. Osmose : eau membrane semi-perméable gradient concentration. Ex: parfum (diffusion), plante flétrie (osmose).

**Q5.** Gonflement, risque éclatement. Eau entre dans cellule (milieu moins concentré).

**Q6.** $6CO_2 + 6H_2O \xrightarrow{\text{lumière}} C_6H_{12}O_6 + 6O_2$. Lumière, chlorophylle, CO₂, eau.

**Q7.** Chloroplastes.

**Q8.** $C_6H_{12}O_6 + 6O_2 \rightarrow 6CO_2 + 6H_2O + \text{énergie (ATP)}$

**Q9.** Photosynthèse : CO₂ + H₂O → glucose + O₂ (endothermique, chloroplastes). Respiration : glucose + O₂ → CO₂ + H₂O + ATP (exothermique, mitochondries).

**Q10.** Oxygène. Test : rallume une allumette éteinte.

**Q11.** Asexuée : 1 parent, clones (bouture, fission). Sexuée : 2 parents, mélange génétique (fécondation).

**Q12.** Spermatozoïde (n) + Ovule (n) → Zygote (2n).

**Q13.** Gamète : cellule haploïde (n). Zygote : cellule diploïde (2n) issue fécondation. Embryon : stade initial développement. Fœtus : stade organes formés.

**Q14.** 9 mois (≈ 39 semaines). 1er trimestre : organogenèse. 2ème : croissance. 3ème : maturation.

**Q15.** Préservatif (barrière), Pilule (hormonale), Stérilet (mécanique/hormonal), Implant, Injection.

**Q16.** Gène : portion ADN codant protéine. Allèle : version d'un gène. Génotype : allèles présents. Phénotype : caractère visible.

**Q17.** F1 : 100% Aa (hétérozygotes). Phénotype dominant.

**Q18.**
| | A | a |
|---|---|---|
| A | AA | Aa |
| a | Aa | aa |
Proportions : 1 AA : 2 Aa : 1 aa. Phénotypes : 3 dominants : 1 récessif.

**Q19.** Allèle dominant masque l'allèle récessif chez hétérozygote. Ex: A (yeux marrons) dominant sur a (yeux bleus).

**Q20.** Écosystème = biotope + biocénose + interactions. Biotope = milieu physique. Biocénose = êtres vivants. Population = individus même espèce même lieu.

**Q21.** Herbe → Sauterelle → Grenouille → Serpent → Épervier.

**Q22.** Effectifs = nb individus par niveau. Biomasse = masse totale matière vivante par niveau.

**Q23.** Perte biodiversité, érosion sols, perturbation cycle eau, changement climat local.

**Q24.** Tri déchets, économie eau/énergie, transport doux, plantation arbres, produits locaux.
