## CORRIGÉ TYPE

**Q1.** Schéma étiqueté correct.

**Q2.** Influx = signal électrique (dépolarisation). Sens : dendrites → corps → axone → terminaisons.

**Q3.** Arrivée influx → libération neurotransmetteurs → fixation récepteurs → déclenchement nouvel influx.

**Q4.** Central = encéphale + moelle épinière. Périphérique = nerfs crâniens + rachidiens.

**Q5.** Récepteur → Neurone sensoriel → Interneurone → Neurone moteur → Effecteur (muscle).

**Q6.** Hormone = messager chimique sécrété par glande endocrine. Transport = sang.

**Q7.** Insuline (β) : baisse glycémie (stockage glucose). Glucagon (α) : hausse glycémie (glycogénolyse).

**Q8.** Type 1 : auto-immun, pas d'insuline → insuline à vie. Type 2 : résistance insuline, souvent obésité → hygiène + antidiabétiques oraux ± insuline.

**Q9.** Thyroxine (T4) / Triiodothyronine : augmente métabolisme basal. Goitre = carence iode → hypertrophie thyroïde.

**Q10.** Testostérone : caractères sexuels mâles, spermatogenèse. Œstrogènes : caractères femelles, cycle. Progestérone : maintien grossesse.

**Q11.** Magmatiques : refroidissement magma (granit, basalte). Sédimentaires : sédiments (grès, calcaire). Métamorphiques : transformation (gneiss, marbre).

**Q12.** Intrusive : lent → gros cristaux (granit). Extrusive : rapide → microscopiques/vitreux (basalte).

**Q13.** Érosion (roche mère) → Transport (eau, vent, glace) → Sédimentation (dépôt) → Diagenèse (compactage, cimentation).

**Q14.** Fossile = trace/vestige être vivant ancien. Datation relative : fossiles guides = même âge.

**Q15.** Superposition : couches inférieures plus anciennes. Continuité : couche s'étend latéralement. Actualisme : processus actuels = passés.

**Q16.** Croûte (5-70 km), Manteau (2900 km), Noyau externe (liquide), Noyau interne (solide).

**Q17.** Lithosphère (croûte + manteau sup.) rigide, flotte sur asthénosphère (manteau sup. ductile). Plaques bougent (cm/an).

**Q18.** Divergence : écartement, dorsale, volcanisme effusif. Convergence : collision, subduction, chaîne montagne, volcanisme explosif, séismes profonds. Transformante : cisaillement, séismes superficiels (San Andreas).

**Q19.** Côtes complémentaires (Amérique/Afrique), même fossiles continents séparés, même roches/âges, paléoclimats (glaciations).

**Q20.** Cameroun : Mont Cameroun (volcan actif), ligne volcanique, faille de Foumban (séismes). Risque modéré.

**Q21.** Schéma cycle : mer → évaporation → nuages → pluie → rivière/infiltration → mer.

**Q22.** Douce < 1 g/L (2,5%), Saumâtre 1-10 g/L, Mer ~35 g/L (97,5%). Majorité glace polaire.

**Q23.** Latitude : angle soleil. Altitude : -6,5°C/km. Océanité : adoucit. Vents : apport air. Relief : barrière pluviométrique.

**Q24.** Rayonnement solaire traverse atmosphère → réchauffement sol → rayonnement infrarouge piégé par GES (CO₂, CH₄, N₂O, vapeur eau) → réchauffement. Conséquences : montée eaux, événements extrêmes, perte biodiversité.
