## CORRIGÉ TYPE

**Q1.** Schéma complet étiqueté.

**Q2.** Salive : amylase (amidon). Gastrique : pepsine + HCl (protéines). Bile : émulsionne graisses. Pancréatique : lipase, amylase, trypsine. Intestinal : disaccharidases, peptidases.

**Q3.** Intestin grêle. Villosités augmentent surface. Transport actif (glucose, AA) et passif (eau, lipides).

**Q4.** Glucides : énergie (céréales). Lipides : réserve, membrane (huiles). Protides : structure, enzymes (viande, légumineuses). Vitamines : coenzymes (fruits/légumes). Minéraux : os, enzymes (lait, légumes). Eau : solvant, transport. Fibres : transit (céréales complètes).

**Q5.** Dénutrition : apport < besoins. Obésité : apport > besoins (IMC > 30). Carence fer : anémie. Vit A : cécité, immunité. Iode : goitre, crétinisme.

**Q6.** Schéma : trachée → bronches → bronchioles → alvéoles (sacs).

**Q7.** Inspiration : diaphragme descend, côtes montent → volume ↑, pression ↓ → air entre. Expiration : relâchement → air sort.

**Q8.** Alvéoles : paroi fine, vascularisées, surfactant. O₂ : air → sang. CO₂ : sang → air. Gradient concentration, grande surface, minceur.

**Q9.** 4 cavités : 2 oreillettes, 2 ventricules. Valves : mitrale, tricuspide, aortique, pulmonaire. Petite : cœur → poumons → cœur. Grande : cœur → corps → cœur.

**Q10.** Artères : épaisse, musculaire, haute pression. Veines : fine, valves, basse pression. Capillaires : 1 cellule, échanges.

**Q11.** ABO : A (Ag A, Ac anti-B), B (Ag B, Ac anti-A), AB (Ag A+B, pas Ac), O (pas Ag, Ac anti-A+B). Rhésus : Rh+ (Ag D), Rh- (pas Ag). Donneur universel : O-. Receveur universel : AB+.

**Q12.** Schéma rein avec zones.

**Q13.** Filtration glomérulaire (pression) → Réabsorption tubulaire (eau, glucose, AA, ions) → Sécrétion tubulaire (H⁺, K⁺, médicaments) → Urine.

**Q14.** Filtre sang → urine (urée, créatinine). Régule volume eau (ADH), Na⁺ (aldostérone), pH (H⁺/HCO₃⁻).

**Q15.** Causes : diabète, HTA, infections, médicaments. Symptômes : fatigue, œdèmes, nausées, anémie. Dialyse : épuration sang artificielle. Greffe : rein donneur.

**Q16.** Double hélice antiparallèle. Bases : A-T (2 liaisons H), G-C (3 liaisons H). Sucre : désoxyribose. Phosphate : liaison phosphodiester.

**Q17.** Hélicase ouvre → Brins modèles → ADN polymérase ajoute nucléotides complémentaires → 2 molécules identiques (1 brin ancien + 1 neuf).

**Q18.** Transcription : noyau, ARN polymérase, ARNm (codons). Traduction : cytoplasme, ribosome, ARNt (anticodons + AA), code génétique (64 codons → 20 AA + STOP).

**Q19.** Mutation = modification séquence ADN. Substitution (1 base), Insertion/Délétion (décalage cadre). Conséquences : neutre, délétère, avantageuse.

**Q20.** OGM : gène étranger inséré (maïs Bt, riz doré). Thérapie génique : gène sain remplace défectueux. CRISPR : ciseaux moléculaires précis. Avantages : santé, agriculture. Risques : éthique, environnement, inégalités.

**Q21.** Variation héréditaire + Sélection naturelle (milieu favorise certains phénotypes) → Adaptation → Évolution.

**Q22.** Fossiles : transitions (Archéoptéryx). Anatomie : organes homologues (membre tétrapode). Embryologie : stades communs. Biochimie : ADN/ protéines universels, similarités.

**Q23.** Population séparée (barrière) → Pas flux gènes → Dérive + Sélection différentes → Nouvelles espèces (isolement reproductif).

**Q24.** Domaines : Bactéries (procaryotes), Archées (procaryotes extrêmophiles), Eucaryotes (noyau). Règnes : Monères, Protistes, Champignons, Plantes, Animaux.

**Q25.** Biodiversité = variété vie. Niveaux : gènes (variabilité intra-espèce), espèces (nb espèces), écosystèmes (variété milieux). Menaces : destruction habitats, surexploitation, pollution, espèces invasives, climat. Conservation : aires protégées, lois, reproduction captivité, éducation.
