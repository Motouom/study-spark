## 1. L'ADN et la réplication

- ADN = double hélice de nucléotides (désoxyribose + phosphate + base azotée).
- Bases : A, T, G, C. Complémentarité : **A–T** (2 liaisons H), **G–C** (3 liaisons H).
- Réplication **semi-conservative** (hélicase + ADN polymérase) → chaque molécule fille garde 1 brin parental.

| Étape         | Lieu       | Molécule        | Enzyme clé      |
| ------------- | ---------- | --------------- | --------------- |
| Réplication   | Noyau      | ADN → ADN       | ADN polymérase  |
| Transcription | Noyau      | ADN → ARNm      | ARN polymérase  |
| Traduction    | Cytoplasme | ARNm → protéine | Ribosome + ARNt |

## 2. Expression du gène

- **Transcription** : ADN → ARNm (la thymine devient uracile U).
- **Traduction** : ARNm lu par codons (triplets) → acides aminés.
- Code génétique : universel, dégénéré (plusieurs codons pour un même acide aminé).
- AUG = Méthionine (initiation) ; UAA/UAG/UGA = stop.

## 3. Génétique mendélienne

- **Monohybridisme Aa × Aa** → rapport phénotypique **3:1** (dominance complète).
- **Dihybridisme AaBb × AaBb** → rapport **9:3:3:1** (gènes indépendants).
- Loi de ségrégation (1ʳᵉ) et loi de l'indépendance des caractères (2ᵉ).

## 4. Mutations et anomalies

- Types : substitution (silencieuse, faux-sens, non-sens), délétion/insertion (décalage du cadre de lecture).
- Germinale (transmissible) vs somatique (non transmissible).
- Caryotype humain : **46 chromosomes** (22 paires autosomes + XX ou XY).
- Trisomie 21 = non-disjonction à la méiose.
- Drépanocytose : mutation E6V du gène HBB (chromosome 11).

## 5. Conseils pour l'examen

- Toujours remplacer T par U dans l'ARNm.
- Vérifier le brin transcrit avant de déduire l'ARNm.
- Bien lire les codons dans l'ordre 5' → 3'.
- Dans un échiquier, écrire d'abord les gamètes des deux parents.
- Citer les lois de Mendel et justifier avec les proportions.

## 6. Pièges classiques

| Erreur                             | Correction                               |
| ---------------------------------- | ---------------------------------------- |
| Confondre transcription/traduction | ADN→ARN / ARN→protéine                   |
| Oublier l'uracile                  | ARN = U au lieu de T                     |
| Dominant/récessif inversé          | Dominant s'exprime à l'état hétérozygote |
