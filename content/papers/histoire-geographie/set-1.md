## CORRIGÉ TYPE

**Q1.** Bamoun, Bamiléké, Lamidats du Nord (Rey-Bouba), Kotoko, Douala, Bassa, Ewondo, Béti.

**Q2.** Roi Njoya (1887-1933) : écriture Shümom, musée, administration centralisée, agriculture, artisanat, islamisation.

**Q3.** Transsaharien : sel, or, esclaves (Nord). Atlantique : traite négrière (côte), puis huile de palme, cacao.

**Q4.** Soudanaises (Nord) : Peuls, Mafa, Toupouri. Bantoues (Sud/Centre/Est) : Bassa, Béti, Ewondo, Douala, Bamiléké, Bamoun. Semi-bantoues (Ouest) : Bamiléké, Bamoun.

**Q5.** 12 juillet 1884. Rois Douala (Bell, Akwa, Deido) signent avec Nachtigal. Protection allemande contre commerce.

**Q6.** Gouverneur, districts, postes. Travail forcé, plantations (cacao, café, caoutchouc), chemins de fer (Nord-Sud, Est).

**Q7.** Manga Bell (Douala) : pétition Société des Nations, pendu 1914. Samba (Bulu) : résistance armée, exécuté 1914.

**Q8.** Perte souveraineté, travail forcé, spoliation terres, introduction monnaie/école/église, dépopulation.

**Q9.** 1919 : France (4/5, Est) / Royaume-Uni (1/5, Ouest). Mandats SDN.

**Q10.** France : administration directe, assimilation, code de l'indigénat, mise en valeur. UK : indirect rule (chefs traditionnels), pas de code indigénat, négligence relative.

**Q11.** UPC 1948 : indépendance immédiate, réunification, réformes sociales. Interdite 1955. Autres : PDC, UC, KNDP (UK).

**Q12.** 1955 : insurrection UPC (maquis). Répression française (villages regroupés, torture). 1958 : loi-cadre Defferre, autonomie. 1960 : indépendance.

**Q13.** 1er janv 1960. Ahidjo 1er président. Adhésion ONU.

**Q14.** Plebiscite 11 fév 1961. Nord → Nigeria. Sud → Cameroun. Réunification 1er oct 1961.

**Q15.** 2 États fédérés (Ouest/Est). Président fédéral, VP, Assemblée fédérale. Tensions : inégalités, centralisation.

**Q16.** Référendum 20 mai 1972. Oui massif. État unitaire, capitale Yaoundé, suppression fédéralisme.

**Q17.** Côte (0-200m), Plateau Sud (600-1000m), Adamaoua (1000-2000m), Volcanique (Mont Cameroun 4095m), Nord (plaine Tchad), Mandara (montagnes).

**Q18.** Chaud/humide toute l'année. Pluies > 1500 mm. Forêt dense (okoumé, ayous, sapelli). Biodiversité.

**Q19.** 2 saisons : sèche (nov-mars), pluie (avr-oct). 1000-1500 mm. Savane arbustive/arborée (karité, néré).

**Q20.** Sanaga (900 km, barrage Song Loulou), Bénoué (affluent Niger), Nyong, Wouri (Douala), Logone (Tchad).

**Q21.** ~28 millions (2023). Densité ~50/km² (inégale : Ouest/Centre dense, Est/Nord faible). Croissance ~2,6%.

**Q22.** Vivrières : autoconsommation + marché local. Export : cacao (1er), café, coton, banane, caoutchouc, palme. Problèmes : prix bas, vieillissement plantations.

**Q23.** Pétrole (offshore, 1er export), Gaz (GNL), Bauxite (Minim-Martap), Fer (Mbalam), Or (artisanal Est), Diamant.

**Q24.** Yaoundé (3M, admin), Douala (4M, port, aéroport, industrie), Garoua (Nord), Bafoussam (Ouest), Maroua (Extrême-Nord), Bamenda (Nord-Ouest).

**Q25.** Pauvreté 37%. Jeunes chômeurs. Corruption (indice faible). Routes/électricité insuffisantes. École : taux achèvement primaire ~70%. Santé : paludisme, VIH, mortalité maternelle.
