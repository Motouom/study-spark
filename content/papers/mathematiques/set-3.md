## CORRIGÉ TYPE

**Q1.** $2x + 6 - 4 = 3x - 3 + 2 \iff 2x + 2 = 3x - 1 \iff x = 3$

**Q2.** $3x - 5 < 2x + 7 \iff x < 12$. Solution : $]-\infty; 12[$

**Q3.** Multiplier la 2ème par 3 : $12x - 3y = 30$. Additionner : $14x = 42 \iff x = 3$. $y = 4x - 10 = 2$.

**Q4.** $3x + 4 = 2x + 16 \iff x = 12$

**Q5.** $2(2x - 1) = 3(x + 2) \iff 4x - 2 = 3x + 6 \iff x = 8$

**Q6.** Volume = $\pi R^2 h = 3,14 \times 16 \times 10 = 502,4 \text{ cm}^3$. Surface latérale = $2\pi Rh = 2 \times 3,14 \times 4 \times 10 = 251,2 \text{ cm}^2$

**Q7.** Volume = $\frac{1}{3}\pi R^2 h = \frac{1}{3} \times 3,14 \times 36 \times 8 = 301,44 \text{ cm}^3$

**Q8.** Volume = $\frac{1}{3} \times \text{Base} \times h = \frac{1}{3} \times 100 \times 12 = 400 \text{ cm}^3$

**Q9.** Volume = $\frac{4}{3}\pi R^3 = \frac{4}{3} \times 3,14 \times 125 = 523,33 \text{ cm}^3$. Surface = $4\pi R^2 = 4 \times 3,14 \times 25 = 314 \text{ cm}^2$

**Q10.** BC = 10 cm (Pythagore). $\sin B = \frac{8}{10} = 0,8$ ; $\cos B = \frac{6}{10} = 0,6$ ; $\tan B = \frac{8}{6} = \frac{4}{3}$

**Q11.** $h^2 = 5^2 - 3^2 = 16 \iff h = 4 \text{ m}$

**Q12.** $\cos 60° = 0,5 \Rightarrow \text{angle} = 60°$

**Q13.** Total = 67, n = 9. Moyenne = 7,44. Médiane = 8 (5ème valeur). Mode = 8. Étendue = 12 - 2 = 10

**Q14.** Total = 10. $P(\text{rouge}) = 0,5$ ; $P(\text{bleue}) = 0,3$ ; $P(\text{verte}) = 0,2$

**Q15.** Paires donnant 7 : (1,6), (2,5), (3,4), (4,3), (5,2), (6,1) → 6 cas sur 36. $P = \frac{1}{6}$

**Q16.** $L \times l = 600$, $L = l + 10$. $l(l+10) = 600 \iff l^2 + 10l - 600 = 0 \iff (l+30)(l-20) = 0 \iff l = 20, L = 30$

**Q17.** Volume total = $\pi \times 1^2 \times 2 = 2\pi \approx 6,28 \text{ m}^3 = 6280 \text{ L}$. Aux 3/4 = 4710 L

**Q18.** Prix achat = 100, Prix vente = 120 (bénéfice 20%). Nouvel achat = 90. Bénéfice = 30. % = $\frac{30}{90} \times 100 = 33,33\%$
