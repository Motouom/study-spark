## CORRIGÉ TYPE

**Q1.** $3x - 7 = 2x + 5 \iff 3x - 2x = 5 + 7 \iff x = 12$

**Q2.** $(x - 4)(2x + 3) = 0 \iff x - 4 = 0$ ou $2x + 3 = 0 \iff x = 4$ ou $x = -1,5$

**Q3.** Par substitution : $x = 18 - y$. $2(18 - y) + 3y = 43 \iff 36 - 2y + 3y = 43 \iff y = 7$. Donc $x = 11$.

**Q4.** Soit $c$ cahiers et $s$ stylos. $\begin{cases} c + s = 12 \\ 300c + 150s = 2700 \end{cases} \iff \begin{cases} c + s = 12 \\ 2c + s = 18 \end{cases} \iff c = 6, s = 6$.

**Q5.** $x^2 - 9 = (x - 3)(x + 3)$ ; $4x^2 - 25 = (2x - 5)(2x + 5)$

**Q6.** $(2x - 3)(x + 4) - (x - 1)^2 = 2x^2 + 8x - 3x - 12 - (x^2 - 2x + 1) = x^2 + 7x - 13$

**Q7.** $A = \frac{1}{2} \times 12 \times 8 = 48 \text{ cm}^2$

**Q8.** $2(L + l) = 36$, $L = 2l \iff 2(2l + l) = 36 \iff 6l = 36 \iff l = 6, L = 12$

**Q9.** $h^2 = 6^2 + 8^2 = 100 \iff h = 10 \text{ cm}$

**Q10.** $C = 2\pi R = 2 \times 3,14 \times 7 = 43,96 \text{ cm}$ ; $A = \pi R^2 = 3,14 \times 49 = 153,86 \text{ cm}^2$

**Q11.** $\text{Moyenne} = \frac{12+15+10+14+13+16+11}{7} = \frac{91}{7} = 13$

**Q12.** $P(\text{pair}) = \frac{3}{6} = \frac{1}{2}$

**Q13.** Garçons = 12. Fréquence = $\frac{12}{30} \times 100 = 40\%$

**Q14.** $v = \frac{240}{3} = 80 \text{ km/h} = \frac{80000}{3600} \approx 22,2 \text{ m/s}$

**Q15.** Bénéfice = $50 \times (500 - 400) = 5000 \text{ FCFA}$

**Q16.** Volume = $25 \times 10 \times 2 = 500 \text{ m}^3 = 500\,000 \text{ litres}$
