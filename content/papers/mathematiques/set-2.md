## CORRIGÉ TYPE

**Q1.** 3 205 047

**Q2.** Entier : 12 346 ; Dixième : 12 345,7 ; Centième : 12 345,68

**Q3.** $\frac{3}{4} + \frac{5}{6} - \frac{1}{3} = \frac{9}{12} + \frac{10}{12} - \frac{4}{12} = \frac{15}{12} = 1 \frac{1}{4}$

**Q4.** $2,5 \times 5 - 16 = 12,5 - 16 = -3,5$

**Q5.** $\frac{84}{126} = \frac{42 \times 2}{42 \times 3} = \frac{2}{3}$

**Q6.** $0,000 045 = 4,5 \times 10^{-5}$ ; $7 800 000 = 7,8 \times 10^6$

**Q7.** $5x - 10 = 3x + 10 \iff 2x = 20 \iff x = 10$

**Q8.** $\frac{4x + 3x}{12} = 7 \iff \frac{7x}{12} = 7 \iff x = 12$

**Q9.** $x = 23 - 4y$. $3(23 - 4y) - 2y = 1 \iff 69 - 12y - 2y = 1 \iff 14y = 68 \iff y = \frac{34}{7}, x = \frac{25}{7}$

**Q10.** $x^2 + 5x + 6 = (x + 2)(x + 3)$ ; $x^2 - 4x - 12 = (x - 6)(x + 2)$

**Q11.** $(x + 3)^2 - (x^2 - 4) = x^2 + 6x + 9 - x^2 + 4 = 6x + 13$

**Q12.** Construction à la règle et au compas (traces visibles)

**Q13.** Angles à la base = $\frac{180° - 40°}{2} = 70°$

**Q14.** Volume = $8 \times 5 \times 3 = 120 \text{ cm}^3$. Surface = $2(8\times5 + 8\times3 + 5\times3) = 2(40+24+15) = 158 \text{ cm}^2$

**Q15.** $h^2 = 9^2 + 12^2 = 225 \iff h = 15 \text{ cm}$

**Q16.** Supplémentaire = $180° - 135° = 45°$ ; Complémentaire = $90° - 135°$ (impossible, angle > 90°)

**Q17.** Coefficient $k = \frac{6}{2} = 3$. $y = 3x$. Tableau : x=8 → y=24 ; x=12 → y=36

**Q18.** $\frac{8}{100} = \frac{x}{350} \iff x = 28 \text{ litres}$

**Q19.** $a = \frac{9-3}{4-1} = 2$. $y = 2x + b$. $3 = 2 + b \iff b = 1$. $y = 2x + 1$

**Q20.** $\frac{500}{4} = \frac{x}{7} \iff x = 875 \text{ g}$

**Q21.** Total = 35. Moyenne = 7. Médiane = 7 (valeur centrale). Étendue = 12 - 3 = 9

**Q22.** Thé : $\frac{120}{200} \times 360° = 216°$ ; Café : $\frac{80}{200} \times 360° = 144°$
