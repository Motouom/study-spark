# Fiche de révision — Chimie organique

## 1. Les fonctions et leur groupe caractéristique

| Fonction    | Groupe                   | Formule       | Exemple                              |
| ----------- | ------------------------ | ------------- | ------------------------------------ |
| Alcane      | —                        | $C_nH_{2n+2}$ | $\text{CH}_4$                        |
| Alcène      | $\text{C}=\text{C}$      | $C_nH_{2n}$   | $\text{C}_2\text{H}_4$               |
| Alcyne      | $\text{C}\equiv\text{C}$ | $C_nH_{2n-2}$ | $\text{C}_2\text{H}_2$               |
| Alcool      | $\text{-OH}$             | R–OH          | $\text{CH}_3\text{OH}$               |
| Aldéhyde    | $\text{-CHO}$            | R–CHO         | $\text{CH}_3\text{CHO}$              |
| Cétone      | $\text{-CO-}$            | R–CO–R'       | $\text{CH}_3\text{COCH}_3$           |
| Acide carb. | $\text{-COOH}$           | R–COOH        | $\text{CH}_3\text{COOH}$             |
| Ester       | $\text{-COO-}$           | R–COO–R'      | $\text{CH}_3\text{COOC}_2\text{H}_5$ |

## 2. Oxydation des alcools (règle essentielle)

- **Primaire** → aldéhyde → acide carboxylique.
- **Secondaire** → cétone.
- **Tertiaire** → pas d'oxydation.
- Un alcool est primaire si le carbone portant –OH porte 2 H ; secondaire s'il porte 1 H ; tertiaire s'il n'en porte pas.

## 3. Estérification et saponification

**Estérification** (acide + alcool → ester + eau) :

- Lente, **limitée** (réversible), athermique.
- Rendement amélioré : excès d'un réactif ou élimination de l'eau.

**Saponification** (ester + base forte → savon + alcool) :

- Rapide, **totale** (irréversible), chauffée.
- Produit un savon (amphiphile : tête hydrophile, queue hydrophobe).

## 4. Polymérisation

- Assemblage de monomères → polymère.
- Exemple : éthylène → polyéthylène : $n\text{CH}_2=\text{CH}_2 \longrightarrow (-\text{CH}_2-\text{CH}_2-)_n$.
- Applications : plastiques, textiles, caoutchouc.

## 5. Tests caractéristiques

- Aldéhyde : Fehling (rouge brique) / Tollens (miroir d'argent).
- Acide carboxylique : réagit avec une base, bleuit le papier pH.
- Ester : odeur fruitée caractéristique.

## 6. Stratégie pour l'examen (Épreuve 2)

1. **Lis le barème** et répartis ton temps (4 sections × 5 exercices).
2. Montre **tous les calculs** avec les unités.
3. Construis le **tableau d'avancement** dès qu'il y a une réaction.
4. Schématise les piles et l'électrolyse (anode/cathode, pont salin).
5. Écris toujours la formule de l'ester/acide/alcool demandé.
6. Relis en vérifiant signes, unités et équilibres de charge.

## 7. Pièges à éviter

- Confondre alcool primaire et secondaire (détermine le produit d'oxydation).
- Confondre estérification (limitée) et saponification (totale).
- Oublier que l'oxydation se fait à l'anode.
- Ne pas écrire les unités des grandeurs calculées.
- Oublier d'équilibrer les équations de combustion.
