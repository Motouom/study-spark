# Fiche de révision — Oxydoréduction et électrochimie

## 1. Vocabulaire clé

- **Oxydation** = perte d'électrons ; **Réduction** = gain d'électrons.
- **Oxydant** = espèce qui capte des électrons (réduite).
- **Réducteur** = espèce qui cède des électrons (oxydée).
- Couple redox : $\text{Ox} + ne^- \rightleftharpoons \text{Red}$.
- Rappel mnémotechnique : **"Ox-Red"** — l'Oxydant capte, le Réducteur cède.

## 2. Règles du nombre d'oxydation (n.o.)

- Élément seul : n.o. = 0.
- H : +1 ; O : −2 (sauf peroxydes).
- Somme des n.o. = 0 (molécule) ou charge (ion).
- Exemples à connaître :
  - Mn dans $\text{MnO}_4^-$ : +7
  - Cr dans $\text{Cr}_2\text{O}_7^{2-}$ : +6
  - N dans $\text{NO}_3^-$ : +5 ; S dans $\text{H}_2\text{SO}_4$ : +6

## 3. Équilibrage d'une réaction redox (milieu acide)

1. Demi-équations séparées.
2. Équilibrer les atomes (H avec $\text{H}^+$, O avec $\text{H}_2\text{O}$).
3. Équilibrer les charges avec $e^-$.
4. Multiplier pour égaliser les $e^-$ et additionner.

## 4. Piles et électrolyse

|          | Pile                  | Électrolyse              |
| -------- | --------------------- | ------------------------ |
| Énergie  | chimique → électrique | électrique → chimique    |
| Réaction | spontanée             | forcée                   |
| Anode    | oxydation, pôle (−)   | oxydation, reliée au (+) |
| Cathode  | réduction, pôle (+)   | réduction, reliée au (−) |

**Anode = toujours le siège de l'oxydation.**

## 5. Lois de Faraday

- Quantité d'électricité : $Q = I \times t$ (C ; A×s)
- $n(e^-) = \frac{Q}{F}$, avec $F = 96\ 500\ \text{C/mol}$
- Masse déposée : $m = n \times M$
- Exemple : $\text{Cu}^{2+} + 2e^- \longrightarrow \text{Cu}$ → 1 mol Cu = 2 mol e⁻.

## 6. Tests d'oxydoréduction utiles

- Liqueur de Fehling : aldéhyde → précipité rouge brique (cétone : rien).
- Liqueur de Tollens : aldéhyde → miroir d'argent.
- Eau de chaux : $\text{CO}_2$ → trouble.

## 7. Pièges fréquents

- Ne pas oublier que l'oxydation est **toujours** à l'anode (pile ou électrolyse).
- Convertir le temps en secondes pour $Q = I \times t$.
- Tenir compte des coefficients : 2 e⁻ pour $\text{Cu}^{2+}$, 1 e⁻ pour $\text{Ag}^+$.
- Vérifier l'équilibre de charge dans l'équation bilan.
