# Fiche de révision — Chimie Terminale

## 1. Chimie quantitative

- Nombre d'Avogadro : $N_A = 6,02 \times 10^{23}\ \text{mol}^{-1}$
- Quantité de matière : $n = \frac{N}{N_A}$
- Masse molaire : $n = \frac{m}{M}$ (avec $m$ en g, $M$ en g/mol)
- Volume molaire (CNTP) : $V_m = 22,4\ \text{L/mol}$, $n = \frac{V}{V_m}$
- Concentration molaire : $C = \frac{n}{V}$ (mol/L)
- Concentration massique : $C_m = \frac{m}{V}$ (g/L), $C_m = C \times M$
- Masse molaire courantes : $M(C)=12$, $M(H)=1$, $M(O)=16$, $M(N)=14$, $M(Na)=23$, $M(Cl)=35,5$, $M(S)=32$, $M(Fe)=56$, $M(Cu)=63,5$, $M(Zn)=65,4$
- Dilution : $C_{mère} \times V_{mère} = C_{fille} \times V_{fille}$
- Rendement : $\eta = \frac{n_{réel}}{n_{théorique}} \times 100$

## 2. Acides et bases

- Définition de Brønsted : acide cède $\text{H}^+$ ; base capte $\text{H}^+$.
- Couple $\text{AH}/\text{A}^-$ : $\text{AH} \rightleftharpoons \text{A}^- + \text{H}^+$
- Produit ionique de l'eau (25 °C) : $K_e = [\text{H}_3\text{O}^+][\text{OH}^-] = 10^{-14}$
- pH : $\text{pH} = -\log[\text{H}_3\text{O}^+]$ ; $[\text{H}_3\text{O}^+] = 10^{-\text{pH}}$
- Acide fort : $[\text{H}_3\text{O}^+] = C$ ; Base forte : $[\text{OH}^-] = C$, $\text{pH} = 14 - \text{pOH}$
- $K_a = \frac{[\text{A}^-][\text{H}_3\text{O}^+]}{[\text{AH}]}$ ; $pK_a = -\log K_a$
- Henderson-Hasselbalch : $\text{pH} = pK_a + \log\frac{[\text{A}^-]}{[\text{AH}]}$
- Taux d'avancement : $\tau = \frac{[\text{H}_3\text{O}^+]}{C}$ (acide faible)

## 3. Tableau des pH

| Solution       | pH                        |
| -------------- | ------------------------- |
| Acide fort $C$ | $\text{pH} = -\log C$     |
| Base forte $C$ | $\text{pH} = 14 + \log C$ |
| Neutre         | pH = 7                    |

## 4. Conseils avant de rendre

- Vérifier les unités (litres, pas mL ; g, pas mg).
- Pour un acide faible, ne jamais écrire $\text{pH} = -\log C$.
- Bien identifier le réactif limitant dans le tableau d'avancement.
- En dose, l'équivalence : $C_A V_A = C_B V_B$ (acide et base monovalents).
- Encadrer la réponse finale avec son unité.

## 5. Valeurs à retenir

- $K_e = 10^{-14}$ à 25 °C.
- $pK_a$ du couple acide acétique/acétate = 4,8 ; $\text{NH}_4^+/\text{NH}_3$ = 9,2.
- Une solution tampon : $\text{pH} \approx pK_a$ quand $[\text{A}^-] \approx [\text{AH}]$.
