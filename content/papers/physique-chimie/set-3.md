## CORRIGÉ TYPE

**Q1.** Onde mécanique = propagation d'une perturbation dans un milieu matériel. Ex: son, vagues.

**Q2.** Transversale : perturbation ⊥ propagation (lumière, corde). Longitudinale : perturbation ∥ propagation (son, ressort).

**Q3.** $v = f \times \lambda = 50 \times 4 = 200 \text{ m/s}$

**Q4.** 1. Angle incidence = angle réflexion. 2. Incident, réfléchi, normale dans même plan.

**Q5.** 30°

**Q6.** $n_1 \sin i_1 = n_2 \sin i_2$

**Q7.** $\sin r = \frac{1}{1,33} \sin 40° = 0,483 \Rightarrow r \approx 28,9°$

**Q8.** Température = degré d'agitation thermique (K). Chaleur = énergie transférée (J).

**Q9.** 100°C = 373 K. 0 K = -273,15°C.

**Q10.** $c$ = chaleur pour élever 1 kg de 1 K. Unité : J/(kg·K).

**Q11.** $Q = m c \Delta T = 2 \times 4180 \times 60 = 501\,600 \text{ J}$

**Q12.** Conduction (solide), Convection (fluide), Rayonnement (vide).

**Q13.** Proton : +e, Neutron : 0, Électron : -e. Noyau = p+n.

**Q14.** Z = nb protons. A = p + n.

**Q15.** Na : (K)2 (L)8 (M)1. Cl : (K)2 (L)8 (M)7. Ca : (K)2 (L)8 (M)8 (N)2.

**Q16.** Ionique : transfert e⁻ (NaCl). Covalente : partage e⁻ (H₂O, Cl₂).

**Q17.** NaCl, H₂O, CO₂.

**Q18.** $pH = -\log[H_3O^+]$. Échelle 0-14. <7 acide, =7 neutre, >7 basique.

**Q19.** $pH = -\log(10^{-3}) = 3$

**Q20.** Basique. $[H_3O^+] = 10^{-10}$ mol/L.

**Q21.** $H^+$ (acide) + $OH^-$ (base) → eau. Neutralisation.

**Q22.** $CH_4 + 2O_2 \rightarrow CO_2 + 2H_2O + \text{énergie}$ (exothermique).

**Q23.** $6CO_2 + 6H_2O \xrightarrow{\text{lumière}} C_6H_{12}O_6 + 6O_2$. Chlorophylle, lumière.

**Q24.** $4Fe + 3O_2 + 6H_2O \rightarrow 4Fe(OH)_3$ (rouille). Prévention : peinture, galvanisation.

**Q25.** Conversion énergie chimique → électrique. Anode (-) : oxydation. Cathode (+) : réduction. Électrolyte : conduction ionique.
