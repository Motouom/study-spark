## CORRIGÉ TYPE

**Q1.** Phrase complexe. Subordonnée : « Parce qu'il pleuvait » (cause, valeur C.C. de cause). Principale : « nous sommes restés à la maison ». Groupe sujet : « nous ». Groupe circonstanciel : « à la maison » (lieu).

**Q2.** Lieu : « à Paris » (Il va à Paris). Temps : « hier » (Il est venu hier). Manière : « avec soin » (Il travaille avec soin).

**Q3.** « Quand le professeur arriva » : subordonnée circonstancielle de temps. « les élèves se turent » : principale. « afin de l'écouter » : subordonnée circonstancielle de but (infinitive).

**Q4.** Conditionnel de politesse : adoucit la demande, marque le respect. L'action est présentée comme conditionnelle pour ne pas imposer.

**Q5.** « Les élèves indisciplinés ont été punis par le directeur. »

**Q6.** « ancien » et « vrai » : épithète (ancien ami, vrai héros). « nouveau » et « certain » : peuvent être attribut (C'est nouveau / C'est certain).

**Q7.** Vouloir : je voudrais... attendez, futur : je voudrai, tu voudras, il voudra, nous voudrons, vous voudrez, ils voudront. / Venir : je viendrai, tu viendras, il viendra, nous viendrons, vous viendrez, ils viendront. / Voir : je verrai, tu verras, il verra, nous verrons, vous verrez, ils verront.

**Q8.** Finir : j'avais fini, tu avais fini, il avait fini... / Boire : j'avais bu... / Ouvrir : j'avais ouvert...

**Q9.** Être : que je fusse, que tu fusses, qu'il fût. / Avoir : que j'eusse, que tu eusses, qu'il eût.

**Q10.** Partir : je serais parti, tu serais parti... / Faire : j'aurais fait, tu aurais fait...

**Q11.** Falloir : falloir / il faut / il a fallu. Pleuvoir : pleuvoir / il pleut / il a plu.

**Q12.** Corrigés : « intérêt », « excès », « hôtel » (accent grave). Formes correctes : réveil (pas d'accent), crème (accent grave).

**Q13.** S'asseoir : je m'assois (ou assieds) / j'ai assis (précision : forme pronominale). Buver : présent du gérondif « buvant » (participe présent).

**Q14.** Commisération : compassion pour la peine d'autrui. Présomption : présomption d'orgueil, jugement hâtif. Flegme : calme imperturbable, sang-froid.

**Q15.** « Il fait **à quatre-vingts degrés** » (fam.) / « Il fait **cuisant** » / « Il est **ravi** » / « Il est **aux anges** ».

**Q16.** « presque » : sur le point de (presque fini = point manquant). « à peu près » : approximativement (mesure approximative).

**Q17.** Autrefois, le village se réunissait le soir autour des contes transmis par le conteur. Aujourd'hui, la télévision l'a remplacé, mais la tradition survit parfois chez les anciens.

**Q18.** Transmetteur de tradition, mémoire orale, éduque (histoires, valeurs, règles), divertit, unit la communauté.

**Q19.** Effets émotionnels : peur (personnages effrayants) et joie (dénouement heureux). Hyperbole/hennement : intensité du plaisir d'écouter.

**Q20.** Le pouvoir de l'oralité : un seul vieillard suffit à ramener l'attention. La tradition n'est pas morte, elle attend un maître. Registre pathétique (nostalgie, espoir).

**Q21.** Registre courant avec registre soutenu (« la case du vieux chef se dressait », « le silence revient »). Exemple soutenu : « les anciens s'y assemblaient ».

**Q22.** Évaluation : respect consigne, pertinence, organisation, correction langue, richesse lexique.
