# Fiche de révision — Gestion, coûts et documents commerciaux

## Les différents coûts

| Coût               | Formule                                           |
| ------------------ | ------------------------------------------------- |
| Coût d'achat       | Prix d'achat + Frais d'achat                      |
| Coût de production | Coût d'achat des matières + Charges de production |
| Coût de revient    | Coût de production + Charges de distribution      |

- **Coût unitaire** = Coût total ÷ Nombre d'unités.
- **Résultat** = Prix de vente − Coût de revient (par unité ou globalement).

## Méthode des centres d'analyse

- Répartir les **charges indirectes** par centres (appro, production, distribution).
- **Coût de l'unité d'œuvre** = Charges du centre ÷ Nombre d'unités d'œuvre.
- Unités d'œuvre : kg de matière, heure de MOD, 100 FCFA de ventes.

## Charges fixes et variables

- **Variables** : proportionnelles à l'activité (matières, MOD).
- **Fixes** : constantes (loyer, salaires fixes).
- **MCV** = CA − Charges variables. **Résultat** = MCV − Charges fixes.

## Seuil de rentabilité

- **Seuil** = Charges fixes ÷ Taux de MCV.
- Taux de MCV = MCV ÷ CA.
- Seuil en quantité = Charges fixes ÷ MCV unitaire.

## Prix de vente

- Marge **sur coût** : Prix HT = Coût × (1 + taux).
- Marge **sur prix de vente HT** : Prix HT = Coût ÷ (1 − taux).
- TVA = Prix HT × 0,1925 ; **Prix TTC = HT + TVA**.

## Analyse des écarts

- **Écart global** = CA réel − CA prévu.
- **Écart quantité** = (Q réelle − Q prévue) × Prix prévu.
- **Écart prix** = (P réel − P prévu) × Q réelle.
- Écart global = écart quantité + écart prix.

## Documents commerciaux

| Document               | Rôle                                                         |
| ---------------------- | ------------------------------------------------------------ |
| Facture                | Preuve de vente (HT + remise − escompte + TVA = net à payer) |
| Avoir                  | Réduction/annulation suite à retour ou erreur                |
| Bon de commande        | Demande/commande d'achat                                     |
| Reçu                   | Preuve de paiement                                           |
| Chèque                 | Moyen de paiement                                            |
| Bordereau de versement | Atteste un dépôt en banque                                   |
| Relevé de compte       | Récapitulatif des mouvements bancaires                       |

## Structure d'une facture

Montant brut − Remise = **Net commercial** − Escompte = **Net financier** + Port = **Net HT** + TVA = **Net à payer** (TTC).

## Conseils pour l'examen

1. Bien lire si la remise/escompte s'appliquent avant ou après le port.
2. Ne pas taxer les emballages consignés.
3. Vérifier sur quel support s'applique la marge (coût ou prix de vente).
4. Faire un état de rapprochement propre en cas d'écart bancaire.
5. Encadrer chaque résultat intermédiaire avec son unité (FCFA).
