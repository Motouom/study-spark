## CORRIGÉ TYPE

**Q1.** Stock : marchandises en magasin. Inventaire : dénombrement des stocks. Coût d'achat : prix d'achat + frais. Coût de revient : coût complet (achat + production + distribution).

**Q2.** CUMP : coût unitaire moyen pondéré. FIFO : premier entré, premier sorti. LIFO : dernier entré, premier sorti.

**Q3.** CUMP = (100×1000 + 200×1200) / (100+200) = (100 000 + 240 000) / 300 = 340 000 / 300 = 1 133,33. Stock final = (300 − 150) × 1 133,33 = 170 000.

**Q4.** FIFO : on sort d'abord les plus anciens (stock = plus récents). LIFO : on sort d'abord les plus récents (stock = plus anciens).

**Q5.** Débit : Variation de stock (charge) ; Crédit : Stock (si stock final < stock initial). Inverse si augmentation.

**Q6.** Salaire brut : salaire avant retenues. Salaire net : brut − retenues. Charges sociales : cotisations sociales. CNPS : Caisse nationale de prévoyance sociale.

**Q7.** CNPS (retraite, maladie), CRTV (radio-télévision), IRPP (impôt sur le revenu), autres cotisations.

**Q8.** Retenues = 300 000 × 15% = 45 000. Salaire net = 300 000 − 45 000 = 255 000.

**Q9.** CNPS : retraite, prestations familiales, risques professionnels, maladie. Protège les travailleurs et leurs familles.

**Q10.** Débit : Salaires (charge) ; Crédit : Banque (net) et CNPS/État (retenues à reverser).

**Q11.** TVA : taxe sur la valeur ajoutée (19,25%). Collectée : sur les ventes. Déductible : sur les achats.

**Q12.** TVA à payer = 200 000 − 150 000 = 50 000.

**Q13.** TVA = 1 000 000 × 19,25% = 192 500. TTC = 1 192 500. Débit : Clients 1 192 500 ; Crédit : Ventes 1 000 000 ; Crédit : TVA collectée 192 500.

**Q14.** TVA = 500 000 × 19,25% = 96 250. TTC = 596 250. Débit : Achats 500 000 ; Débit : TVA déductible 96 250 ; Crédit : Fournisseurs 596 250.

**Q15.** L'IS est l'impôt sur les bénéfices des entreprises (taux ~30%). Il finance le budget de l'État.

**Q16.** FR : capitaux permanents − actif immobilisé. BFR : actif circulant − passif circulant. TN : trésorerie disponible.

**Q17.** FR = 8 000 000 − 6 000 000 = 2 000 000.

**Q18.** FR = BFR + TN. Si FR > BFR, TN positive (excédent). Si FR < BFR, TN négative (découvert).

**Q19.** Liquidité : capacité à payer à court terme. Solvabilité : capacité à rembourser les dettes. Rentabilité : capacité à générer du profit.

**Q20.** La trésorerie permet de payer les fournisseurs, les salaires, les impôts. Une trésorerie insuffisante mène à la faillite.

**Q21.** Seuil de rentabilité : chiffre d'affaires où le résultat est nul. Marge : différence prix/coût. Coût variable : varie avec l'activité. Coût fixe : constant.

**Q22.** SR = Charges fixes / Taux de marge = 1 000 000 / 0,40 = 2 500 000.

**Q23.** Variable : matières premières, énergie (varie avec production). Fixe : loyer, salaires fixes, amortissements (constant).

**Q24.** Budget : prévision des recettes/dépenses. Tableau de bord : indicateurs de suivi. Prévisionnel : projections financières.

**Q25.** Le comptable fournit des informations fiables (coûts, résultats, trésorerie) qui éclairent les décisions de gestion.
