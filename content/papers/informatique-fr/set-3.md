## CORRIGÉ TYPE

**Q1.** Réseau : ensemble d'ordinateurs connectés. LAN : réseau local. WAN : réseau étendu. Internet : réseau mondial. Intranet : réseau interne à une organisation.

**Q2.** Routeur (dirige le trafic), modem (connexion Internet), switch (relie les machines), câbles (Ethernet), Wi-Fi (connexion sans fil).

**Q3.** Adresse IP : identifiant numérique d'une machine sur le réseau (ex : 192.168.1.1). Nom de domaine : nom lisible d'un site (ex : google.com), traduit en IP par le DNS.

**Q4.** Navigateurs : Chrome, Firefox, Edge, Safari. Moteurs : Google, Bing, Yahoo, DuckDuckGo.

**Q5.** Site web : pages consultées via navigateur. Application mobile : logiciel installé sur smartphone, souvent plus rapide et adapté au mobile.

**Q6.** E-mail (Gmail, Outlook), messagerie instantanée (WhatsApp, Telegram), visioconférence (Zoom, Meet, Teams), réseaux sociaux (Facebook, Instagram, TikTok).

**Q7.** Ouvrir la messagerie → Nouveau message → destinataire, objet, texte → joindre un fichier (trombone) → Envoyer.

**Q8.** Être poli, ne pas écrire en majuscules (crier), ne pas partager d'informations personnelles, respecter les autres, vérifier avant d'envoyer, pas de spam.

**Q9.** Permettent de travailler à plusieurs sur les mêmes documents en temps réel, de partager des fichiers, de communiquer, où que l'on soit.

**Q10.** Forum : espace de discussion. Blog : journal en ligne. Wiki : site modifiable par les utilisateurs (Wikipédia). Podcast : émission audio téléchargeable.

**Q11.** Cybercriminalité : activités illégales via Internet. Piratage : accès non autorisé à un système. Malware : logiciel malveillant. Ransomware : logiciel qui bloque les données contre rançon.

**Q12.** Virus : s'attache à un fichier. Ver : se propage seul sur le réseau. Cheval de Troie : se déguise en logiciel légitime. Spyware : espionne l'utilisateur.

**Q13.** Au moins 12 caractères, majuscules, minuscules, chiffres, symboles, pas de mots du dictionnaire, pas d'informations personnelles, différent pour chaque compte.

**Q14.** Les mises à jour corrigent les failles de sécurité, améliorent les performances et protègent contre les nouvelles menaces.

**Q15.** Ne pas partager ses données, vérifier les paramètres de confidentialité, se méfier des sites douteux, ne pas publier d'informations sensibles, utiliser des mots de passe forts.

**Q16.** Données personnelles : informations identifiant une personne (nom, adresse, photos). Vie privée : droit de contrôler ses informations. Identité numérique : ensemble des traces laissées en ligne.

**Q17.** Vol d'identité, usurpation, harcèlement, arnaques, mauvaise réputation, exploitation des données.

**Q18.** Droit à l'oubli : demander la suppression de ses données. Droit à l'information : savoir comment ses données sont utilisées. Droit d'auteur : protection des créations.

**Q19.** Droit d'auteur : l'auteur contrôle l'utilisation de son œuvre. Plagiat : copier le travail d'autrui sans citer la source. C'est une faute morale et légale.

**Q20.** Ne pas répondre, bloquer l'agresseur, signaler sur la plateforme, en parler à un adulte de confiance, conserver les preuves, ne pas partager ses coordonnées.

**Q21.** Algorithme : Pour i de 1 à 10 Faire ; Écrire i ; FinPour.

**Q22.** Algorithme : Lire N ; Si N mod 2 = 0 Alors Écrire « Pair » Sinon Écrire « Impair » FinSi.

**Q23.** Algorithme : Lire A, B, C ; M ← (A + B + C) / 3 ; Écrire M.

**Q24.** Variable : valeur qui peut changer pendant l'exécution. Constante : valeur fixe qui ne change jamais.

**Q25.** 1. Analyse du problème. 2. Conception de l'algorithme. 3. Codage dans un langage. 4. Compilation/interprétation. 5. Test et débogage. 6. Documentation et maintenance.
