## CORRIGÉ TYPE

**Q1.** Informatique : science du traitement automatique de l'information. Ordinateur : machine électronique qui traite des données. Donnée : information brute. Information : donnée traitée et interprétée.

**Q2.** Unité centrale (processeur, RAM, disque), écran (affichage), clavier (saisie), souris (pointage), imprimante (sortie papier).

**Q3.** Matériel : composants physiques (processeur, écran, clavier). Logiciel : programmes (Windows, Word, navigateur).

**Q4.** Bureau (fixe), portable, tablette, smartphone, serveur (centralise données/services).

**Q5.** Le système d'exploitation gère le matériel, les fichiers, les programmes, l'interface utilisateur. Exemples : Windows, Linux, macOS, Android, iOS.

**Q6.** Bit (0 ou 1), Octet (8 bits), Ko (1024 octets), Mo (1024 Ko), Go (1024 Mo), To (1024 Go).

**Q7.** 1 Ko = 1024 octets ; 1 Mo = 1024 Ko ; 1 Go = 1024 Mo.

**Q8.** Disque dur (HDD), SSD (rapide), clé USB, carte mémoire (SD), CD/DVD, stockage en ligne (cloud).

**Q9.** RAM : mémoire temporaire, rapide, effacée à l'extinction. Mémoire de masse : stockage permanent des données (disque, clé).

**Q10.** Cloud : stockage et services accessibles via Internet (Google Drive, OneDrive, Dropbox). Avantages : accessibilité, sauvegarde, partage, pas de matériel local.

**Q11.** Traitement de texte : Word, LibreOffice Writer. Tableur : Excel, LibreOffice Calc. Présentation : PowerPoint, LibreOffice Impress.

**Q12.** Créer, modifier, mettre en forme des documents texte : lettres, rapports, devoirs. Correcteur orthographique, insertion d'images, tableaux.

**Q13.** Organiser et calculer des données en tableaux, formules, graphiques. Utile pour budgets, notes, statistiques.

**Q14.** Navigateurs : Chrome, Firefox, Edge, Safari. Messagerie : Gmail, Outlook, Yahoo Mail.

**Q15.** Libre : code source ouvert, gratuit, modifiable (Linux, LibreOffice, Firefox). Propriétaire : code fermé, payant, licence (Windows, Microsoft Office, Photoshop).

**Q16.** Internet : réseau mondial d'ordinateurs. Navigateur : logiciel pour consulter le web. Moteur de recherche : outil pour trouver des pages (Google, Bing). Site web : ensemble de pages en ligne.

**Q17.** Web (pages), E-mail (courrier électronique), Réseaux sociaux (Facebook, WhatsApp), Visioconférence (Zoom, Meet), E-commerce (achat en ligne).

**Q18.** Mot de passe : code secret d'accès. Virus : programme malveillant. Antivirus : logiciel de protection. Phishing : tentative de vol de données par usurpation.

**Q19.** Utiliser des mots de passe forts et différents, ne pas partager ses identifiants, se méfier des liens inconnus, mettre à jour ses logiciels, installer un antivirus, ne pas divulguer ses informations personnelles.

**Q20.** Cyberharcèlement : insultes et menaces en ligne. Fausses informations : rumeurs et désinformation. Dépendance : temps excessif, isolement, baisse des résultats scolaires.

**Q21.** Algorithme : suite ordonnée d'étapes pour résoudre un problème. Programme : algorithme écrit dans un langage. Langage : moyen de communication avec l'ordinateur (Python, Java, C).

**Q22.** 1. Analyse du problème. 2. Conception de l'algorithme. 3. Codage dans un langage. 4. Test et correction.

**Q23.** Algorithme Somme : Début ; Lire A ; Lire B ; S ← A + B ; Écrire S ; Fin.

**Q24.** Python (généraliste, data), Java (applications, Android), C/C++ (systèmes, jeux), JavaScript (web).

**Q25.** Boucle : répète des instructions (Pour i de 1 à 10, Répéter...Jusqu'à). Condition : exécute selon une condition (Si...Alors...Sinon). Exemple : Si note ≥ 10 Alors « admis » Sinon « ajourné ».
