## CORRIGÉ TYPE

**Q1.** Processeur (CPU), mémoire RAM, disque dur/SSD, carte mère, carte graphique, alimentation, carte réseau.

**Q2.** Le processeur exécute les instructions des programmes, effectue les calculs et coordonne les composants. C'est le « cerveau » de l'ordinateur.

**Q3.** La carte mère relie tous les composants (processeur, RAM, disques, périphériques) et assure leur communication.

**Q4.** Entrée : clavier, souris, scanner, microphone, webcam. Sortie : écran, imprimante, haut-parleurs. Entrée-sortie : écran tactile, clé USB, disque externe.

**Q5.** Entrée : envoie des données à l'ordinateur (clavier, souris). Sortie : reçoit des données de l'ordinateur (écran, imprimante).

**Q6.** Gérer le matériel, les fichiers, la mémoire, les programmes, l'interface utilisateur, la sécurité, les utilisateurs.

**Q7.** Mise sous tension → BIOS/UEFI (test du matériel) → chargement du système d'exploitation → affichage du bureau → lancement des programmes.

**Q8.** Fichier : unité de données (document, image, musique). Dossier : conteneur de fichiers organisés en arborescence.

**Q9.** .docx (Word), .xlsx (Excel), .pptx (PowerPoint), .pdf (document portable), .jpg (image), .mp3 (audio), .mp4 (vidéo).

**Q10.** Protège contre la perte (panne, virus, vol). Sauvegarder sur support externe ou cloud, régulièrement.

**Q11.** Barre de titre (nom du document), ruban (onglets et outils), zone de travail (texte), barre d'état (informations, zoom).

**Q12.** Sélectionner le texte puis utiliser les boutons : gras (B), italique (I), souligné (U), police, taille, alignement (gauche, centre, droite, justifié).

**Q13.** Menu Insertion : image (depuis fichier), tableau (lignes/colonnes), numéro de page (en-tête/pied de page).

**Q14.** Enregistrer : sauvegarde dans le même fichier. Enregistrer sous : sauvegarde sous un autre nom/emplacement/format.

**Q15.** En-tête avec logo et titre, marges correctes, police lisible, interligne, numérotation des pages, signature, date.

**Q16.** Cellule : intersection ligne/colonne (ex : B3). Ligne : horizontale. Colonne : verticale. Plage : ensemble de cellules (A1:C5). Feuille : page du classeur.

**Q17.** Formule : calcul écrit par l'utilisateur (=A1+B1). Fonction : formule prédéfinie (=SOMME(A1:A10)).

**Q18.** SOMME (addition), MOYENNE (moyenne), MAX (maximum), MIN (minimum), NB (nombre de valeurs).

**Q19.** Sélectionner les données → menu Insertion → Graphique → choisir le type (barres, courbe, secteurs) → personnaliser.

**Q20.** Tri : organiser les données (croissant/décroissant). Filtre : afficher uniquement les données répondant à un critère.

**Q21.** Titre, texte, images, animations (mouvements d'éléments), transitions (effets entre diapositives).

**Q22.** Texte court et lisible, images pertinentes, couleurs contrastées, cohérence, ne pas surcharger, parler plutôt que lire.

**Q23.** Image : représentation visuelle. Son : signal audio. Vidéo : séquence d'images animées avec son. Animation : mouvement d'éléments.

**Q24.** JPEG (photos, compressé), PNG (transparence), GIF (animations), BMP (non compressé, lourd).

**Q25.** Rend l'apprentissage plus vivant et motivant, facilite la compréhension (schémas, vidéos), permet l'accès à des ressources variées.
