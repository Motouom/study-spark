# Fiche de révision 1 — Concepts économiques fondamentaux

## Définitions clés

- **Économie** : science de l'administration des ressources rares ; étudie la production, la répartition et la consommation des richesses.
- **Rareté** : insuffisance des ressources face à des besoins illimités.
- **Besoin** : état de manque que l'on cherche à satisfaire (primaire, secondaire, superflus).
- **Bien** : objet matériel (nourriture, vêtement).
- **Service** : prestation immatérielle, produite et consommée en même temps (transport, santé).

## Les trois questions économiques

| Question            | Sens                            |
| ------------------- | ------------------------------- |
| Quoi produire ?     | Nature et quantité des biens    |
| Comment produire ?  | Techniques et facteurs utilisés |
| Pour qui produire ? | Répartition de la production    |

## Classification des biens

- **Libres** : abondants, gratuits (air, eau de mer).
- **Économiques** : rares, produits par le travail (riz, habits).
- De **consommation** vs de **production** ; **durables** vs **non durables** ; **substituts** vs **complémentaires**.

## Valeur et utilité

- **Valeur d'usage** = utilité (satisfaction procurée).
- **Valeur d'échange** = ce qu'on donne pour obtenir le bien.
- **Utilité totale** : satisfaction globale ; **utilité marginale** : satisfaction d'une unité supplémentaire (décroissante).

## Agents économiques

| Agent                    | Rôle                                      |
| ------------------------ | ----------------------------------------- |
| Ménages                  | Consomment, épargnent, offrent le travail |
| Entreprises              | Produisent, investissent, créent l'emploi |
| État                     | Biens publics, redistribution, régulation |
| Institutions financières | Collectent l'épargne, accordent le crédit |
| Reste du monde           | Échanges extérieurs                       |

## Opérations économiques

- **Production** : création de biens/services.
- **Répartition** : distribution des revenus.
- **Consommation** : usage des biens pour satisfaire les besoins.
- **Épargne** : revenu non consommé.
- **Investissement** : achat de biens de production.

## Circuit économique

- **Flux réels** : biens, services, travail (ménages → entreprises : travail ; entreprises → ménages : biens).
- **Flux monétaires** : paiements en sens inverse (salaires, achats).

## Formules

- **PMC** = Consommation / Revenu
- **PmC** = ΔConsommation / ΔRevenu
- **Productivité du travail** = Production / Nombre de travailleurs
