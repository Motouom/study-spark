# Fiche de révision — Ondes, optique et physique moderne (Terminale)

## Ondes

- Relation fondamentale : $v = \lambda f = \frac{\lambda}{T}$
- La fréquence est invariante au changement de milieu ; $v$ et $\lambda$ changent.
- Diffraction : $\theta = \frac{\lambda}{a}$ ; largeur tache centrale : $\ell = 2\theta D$
- Interférences : constructive $\delta = k\lambda$ ; destructive $\delta = (2k+1)\frac{\lambda}{2}$
- Fentes d'Young : $i = \frac{\lambda D}{a}$
- Célérité dans un milieu : $v = \frac{c}{n}$
- Célérité du son dans l'air : ~340 m/s ; lumière dans le vide : $c = 3\times10^8$ m/s

## Optique géométrique

- Snell-Descartes : $n_1\sin i = n_2\sin r$
- Angle limite : $\sin i_c = \frac{n_2}{n_1}$
- Lentilles : $\frac{1}{\overline{OA'}} - \frac{1}{\overline{OA}} = \frac{1}{f'}$
- Grandissement : $\gamma = \frac{\overline{OA'}}{\overline{OA}} = \frac{\overline{A'B'}}{\overline{AB}}$
- Vergence : $V = \frac{1}{f'}$ (dioptrie)
- Objet réel : $\overline{OA} < 0$ ; Image réelle : $\overline{OA'} > 0$

## Physique quantique (lumière)

- Énergie du photon : $E = h\nu = h\frac{c}{\lambda}$ ($h = 6,6\times10^{-34}$ J·s)
- Effet photoélectrique : $E_c = h\nu - W_0$
- Fréquence seuil : $f_0 = \frac{W_0}{h}$
- $1 \text{ eV} = 1,6\times10^{-19}$ J

## Radioactivité

- Loi de décroissance : $N(t) = N_0 e^{-\lambda t}$
- Demi-vie : $T = \frac{\ln 2}{\lambda}$ ($\ln 2 \approx 0,693$)
- Activité : $A = \lambda N$ (Bq) ; $A_0 = \lambda N_0$
- Après $n$ demi-vies : $N = \frac{N_0}{2^n}$
- **$\alpha$** : $\phantom{}_{Z}^{A}\text{X} \rightarrow \phantom{}_{Z-2}^{A-4}\text{Y} + \phantom{}_{2}^{4}\text{He}$
- **$\beta^-$** : $\phantom{}_{Z}^{A}\text{X} \rightarrow \phantom{}_{Z+1}^{A}\text{Y} + \phantom{}_{-1}^{0}e + \bar{\nu}$

## Énergie nucléaire

- Einstein : $E = \Delta m c^2$
- $1 \text{ u} = 931,5 \text{ MeV/c}^2$ ; $1 \text{ MeV} = 1,6\times10^{-13}$ J
- Fission : noyau lourd → noyaux plus légers + énergie
- Fusion : noyaux légers → noyau plus lourd + énergie (Soleil)

## Constantes et conversions

- $c = 3\times10^8$ m/s ; $h = 6,6\times10^{-34}$ J·s ; $e = 1,6\times10^{-19}$ C
- $1 \text{ nm} = 10^{-9}$ m ; $1 \text{ u} = 1,66\times10^{-27}$ kg

## Conseils pour l'examen

1. Convertir les longueurs d'onde en mètres.
2. Distinguer diffraction (obstacle) et réfraction (milieu).
3. Vérifier les lois de conservation (A et Z) dans les réactions nucléaires.
4. Comparer toujours $h\nu$ avec $W_0$ pour l'effet photoélectrique.
5. Noter le signe des distances algébriques en optique.
