## SECTION 1 : MÉCANIQUE

## CORRIGÉ

**Exercice 1.** 1) $a = \frac{F}{m} = \frac{20}{4} = 5 \text{ m/s}^2$. 2) $v = at = 5\times5 = 25 \text{ m/s}$. 3) $p = mv = 4\times25 = 100 \text{ kg}\cdot\text{m/s}$. 4) $E_c = \frac{1}{2}mv^2 = \frac{1}{2}\times4\times625 = 1250 \text{ J}$.

**Exercice 2.** 1) $p_A = 1\times6 = 6$ ; $p_B = 2\times(-3) = -6$ ; $p_{tot} = 0 \text{ kg}\cdot\text{m/s}$. 2) Conservation : $p_{tot} = (m_A + m_B)v \Rightarrow v = 0 \text{ m/s}$. 3) Vitesse nulle (les deux mobiles s'arrêtent ensemble).

**Exercice 3.** 1) $r = R_T + h = 6400 + 200 = 6600 \text{ km} = 6,6\times10^6 \text{ m}$. 2) $g' = G\frac{M_T}{r^2} = 6,67\times10^{-11}\times\frac{6\times10^{24}}{(6,6\times10^6)^2} = \frac{4\times10^{14}}{4,356\times10^{13}} = 9,19 \text{ m/s}^2$. 3) $v = \sqrt{g'r} = \sqrt{9,19\times6,6\times10^6} = \sqrt{6,07\times10^7} = 7790 \text{ m/s}$.

**Exercice 4.** 1) $mg = kx \Rightarrow x = \frac{0,5\times10}{100} = 0,05 \text{ m}$. 2) $\omega_0 = \sqrt{\frac{k}{m}} = \sqrt{\frac{100}{0,5}} = \sqrt{200} = 14,1 \text{ rad/s}$ ; $T = 2\pi\sqrt{\frac{m}{k}} = 2\pi\sqrt{0,005} = 0,445 \text{ s}$. 3) $f = \frac{1}{T} = 2,25 \text{ Hz}$.

**Exercice 5.** 1) $E_m = \frac{1}{2}mv^2 = \frac{1}{2}\times0,1\times36 = 1,8 \text{ J}$. 2) $h = \frac{v^2}{2g} = \frac{36}{20} = 1,8 \text{ m}$. 3) $E' = 0,8\times1,8 = 1,44 \text{ J}$ ; $h' = \frac{1,44}{0,1\times10} = 1,44 \text{ m}$.

**Exercice 6.** 1) $I = \frac{E}{R+r} = \frac{12}{12} = 1 \text{ A}$. 2) $U = E - rI = 12 - 2 = 10 \text{ V}$. 3) $P = UI = 10\times1 = 10 \text{ W}$.

**Exercice 7.** 1) $C_{eq} = C_1 + C_2 = 9 \ \mu\text{F}$. 2) $Q = C_{eq}U = 9\times10^{-6}\times50 = 4,5\times10^{-4} \text{ C}$. 3) $E = \frac{1}{2}C_{eq}U^2 = \frac{1}{2}\times9\times10^{-6}\times2500 = 0,01125 \text{ J}$.

**Exercice 8.** 1) $F = qvB = 1,6\times10^{-19}\times2\times10^6\times0,5 = 1,6\times10^{-13} \text{ N}$. 2) La force de Lorentz est perpendiculaire à la vitesse, donc elle ne travaille pas : seule la direction change. 3) $R = \frac{mv}{qB} = \frac{1,67\times10^{-27}\times2\times10^6}{1,6\times10^{-19}\times0,5} = 4,18\times10^{-2} \text{ m}$.

**Exercice 9.** 1) $\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{0,4\times10\times10^{-6}}} = \frac{1}{\sqrt{4\times10^{-6}}} = 500 \text{ rad/s}$. 2) $f_0 = \frac{\omega_0}{2\pi} = 79,6 \text{ Hz}$. 3) L'énergie s'échange périodiquement entre le condensateur (énergie électrique) et la bobine (énergie magnétique), sans perte dans un circuit idéal.

**Exercice 10.** 1) $\frac{U_2}{U_1} = \frac{N_2}{N_1} \Rightarrow N_2 = 1150\times\frac{23}{230} = 115$ spires. 2) $I_1 = I_2\frac{N_2}{N_1} = 5\times\frac{115}{1150} = 0,5 \text{ A}$. 3) $P = U_2I_2 = 23\times5 = 115 \text{ W}$.

**Exercice 11.** 1) $d = v\Delta t = 340\times0,02 = 6,8 \text{ m}$. 2) Distance obstacle $= \frac{6,8}{2} = 3,4 \text{ m}$. 3) Détection d'obstacles sous-marins, bathymétrie, sonar de pêche.

**Exercice 12.** 1) $\frac{1}{\overline{OA'}} = \frac{1}{5} + \frac{1}{-6} = \frac{1}{5} - \frac{1}{6} = \frac{1}{30} \Rightarrow \overline{OA'} = 30 \text{ cm}$. 2) $\gamma = \frac{30}{-6} = -5$. 3) Taille $= |\gamma|\times1 \text{ mm} = 5 \text{ mm}$, image renversée.

**Exercice 13.** 1) $n_1\sin i = n_2\sin r \Rightarrow \sin r = 1,33\sin45° = 1,33\times0,707 = 0,94 \Rightarrow r = 70,1°$. 2) $\sin i_c = \frac{n_2}{n_1} = \frac{1}{1,33} = 0,752 \Rightarrow i_c = 48,8°$. 3) Pour $i = 70° > i_c$, réflexion totale (pas de réfraction).

**Exercice 14.** 1) $i = \frac{\lambda D}{a} = \frac{600\times10^{-9}\times1}{10^{-3}} = 6\times10^{-4} \text{ m} = 0,6 \text{ mm}$. 2) 3e frange brillante : $x = 3i = 1,8 \text{ mm}$. 3) Superposition de deux ondes cohérentes créant des maxima (constructifs) et minima (destructifs).

**Exercice 15.** 1) $\sin r = \frac{\sin 50°}{1,5} = \frac{0,766}{1,5} = 0,511 \Rightarrow r = 30,7°$. 2) $v = \frac{c}{n} = \frac{3\times10^8}{1,5} = 2\times10^8 \text{ m/s}$. 3) $n_1\sin i = n_2\sin r$ (loi de Snell-Descartes).

**Exercice 16.** 1) $\lambda = \frac{0,693}{24} = 0,0289 \text{ jour}^{-1}$. 2) $A = A_0(1/2)^2 = \frac{10^{12}}{4} = 2,5\times10^{11} \text{ Bq}$. 3) $N_0 = \frac{A_0}{\lambda} = \frac{10^{12}}{0,0289} = 3,46\times10^{13}$ noyaux.

**Exercice 17.** 1) $E = 2\times1,6\times10^{-19} = 3,2\times10^{-19} \text{ J}$. 2) $f = \frac{E}{h} = \frac{3,2\times10^{-19}}{6,6\times10^{-34}} = 4,85\times10^{14} \text{ Hz}$. 3) $\lambda = \frac{c}{f} = \frac{3\times10^8}{4,85\times10^{14}} = 6,19\times10^{-7} \text{ m} = 619 \text{ nm}$.

**Exercice 18.** 1) Masse : $210 = 206 + 4$ ✓ ; charge : $84 = 82 + 2$ ✓. 2) $E = 0,0058\times931,5 = 5,40 \text{ MeV}$. 3) $E = 5,40\times1,6\times10^{-13} = 8,65\times10^{-13} \text{ J}$.

**Exercice 19.** 1) $A = 3,7\times10^{10}$ désintégrations/s. 2) Puissance $= 3,7\times10^{10}\times5\times1,6\times10^{-13} = 0,0296 \text{ J/s}$. 3) Rayonnement ionisant : risque de mutations, cancers ; se protéger par blindage, distance, durée.

**Exercice 20.** 1) $\phantom{}_{86}^{222}\text{Rn} \rightarrow \phantom{}_{84}^{218}\text{Po} + \phantom{}_{2}^{4}\text{He}$. 2) $\lambda = \frac{0,693}{3,8} = 0,182 \text{ jour}^{-1}$. 3) $A = A_0(1/2)^2 = \frac{2\times10^{10}}{4} = 5\times10^9 \text{ Bq}$.
