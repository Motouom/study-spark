# Fiche de révision — Mécanique (Terminale)

## Cinématique

- Vitesse moyenne : $v_{moy} = \frac{\Delta d}{\Delta t}$
- MRU : $x = x_0 + vt$, $a = 0$
- MRUV : $v = v_0 + at$ ; $x = x_0 + v_0t + \frac{1}{2}at^2$ ; $v^2 = v_0^2 + 2a\Delta x$
- Chute libre : $v = \sqrt{2gh}$ ; $h = \frac{1}{2}gt^2$ ; $t = \sqrt{\frac{2h}{g}}$
- **Conversion :** $v(\text{m/s}) = \frac{v(\text{km/h})}{3,6}$

## La dynamique

- PFD : $\sum \vec{F}_{ext} = m\vec{a}$
- Poids : $P = mg$
- Ressort : $F = kx$ ; Frottement : $f = \mu R_N$
- Gravitation : $F = G\frac{m_1m_2}{d^2}$ ($G = 6,67\times10^{-11}$ SI)

## Énergie

- Énergie cinétique : $E_c = \frac{1}{2}mv^2$
- Travail : $W = Fd\cos\theta$ ; travail du poids : $W(P) = mg(z_1 - z_2)$
- Énergie potentielle de pesanteur : $E_{pp} = mgz$
- Énergie potentielle élastique : $E_{pe} = \frac{1}{2}kx^2$
- Th. énergie cinétique : $\Delta E_c = \sum W(F)$
- Énergie mécanique : $E_m = E_c + E_p$ (se conserve si forces conservatives)
- Puissance : $P = \frac{W}{t} = Fv$

## Mouvement circulaire uniforme

- Période : $T = \frac{2\pi R}{v}$ ; fréquence : $f = \frac{1}{T}$
- Accélération centripète : $a_n = \frac{v^2}{R} = \omega^2R$
- Force centripète : $F = m\frac{v^2}{R}$
- Vitesse angulaire : $\omega = \frac{2\pi}{T}$
- Vitesse de satellisation : $v = \sqrt{\frac{GM_T}{r}}$

## Oscillations

- Pendule : $T = 2\pi\sqrt{\frac{l}{g}}$
- Ressort : $\omega_0 = \sqrt{\frac{k}{m}}$ ; $T = 2\pi\sqrt{\frac{m}{k}}$

## Quantité de mouvement et chocs

- $p = mv$ (kg·m/s)
- Conservation : $p_{avant} = p_{après}$ (système isolé)
- Choc inélastique : $v = \frac{m_1v_1 + m_2v_2}{m_1 + m_2}$

## Unités et constantes

- $g = 10 \text{ m/s}^2$ ; $1 \text{ kg} = 1000 \text{ g}$
- Force : N ; Travail/Énergie : J ; Puissance : W ; $1 \text{ kW} = 1000 \text{ W}$

## Conseils pour l'examen

1. Convertir toutes les unités avant de calculer.
2. Faire le bilan des forces et le schéma.
3. Vérifier le signe du travail (motrice +, résistante −).
4. Encadrer le résultat avec son unité.
5. Relire la cohérence du résultat (ordre de grandeur).
