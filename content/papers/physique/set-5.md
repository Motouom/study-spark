## SECTION 1 : MÉCANIQUE

## CORRIGÉ

**Exercice 1.** 1) Poids $\vec{P}$ vers le bas, tension $\vec{T}$ vers le haut. 2) $T - P = ma \Rightarrow T = m(g + a) = 500 \times 12 = 6\,000 \text{ N}$. 3) $v^2 = 2ad \Rightarrow d = \frac{9}{4} = 2,25 \text{ m}$.

**Exercice 2.** 1) $E_p = mgh = 0,2\times10\times20 = 40 \text{ J}$. 2) À mi-hauteur, $h = 10$ : $\frac{1}{2}mv^2 = mg(20-10) \Rightarrow v^2 = 2\times10\times10 = 200 \Rightarrow v = 14,1 \text{ m/s}$. 3) $v = \sqrt{2gh} = \sqrt{400} = 20 \text{ m/s}$.

**Exercice 3.** 1) $h = 1(1 - \cos30°) = 1 - 0,866 = 0,134 \text{ m}$. 2) $v = \sqrt{2gh} = \sqrt{2\times10\times0,134} = \sqrt{2,68} = 1,64 \text{ m/s}$. 3) $T = 2\pi\sqrt{\frac{l}{g}} = 2\pi\sqrt{0,1} = 1,99 \text{ s}$.

**Exercice 4.** 1) $f = \mu mg = 0,25\times2\times10 = 5 \text{ N}$. 2) $ma = F - f \Rightarrow a = \frac{15-5}{2} = 5 \text{ m/s}^2$. 3) $v = at = 5\times4 = 20 \text{ m/s}$.

**Exercice 5.** 1) $W(P) = -mgh = -500\times10\times10 = -50\,000 \text{ J}$. 2) $t = \frac{mgh}{P} = \frac{50\,000}{2000} = 25 \text{ s}$. 3) $v = \frac{h}{t} = \frac{10}{25} = 0,4 \text{ m/s}$.

**Exercice 6.** 1) $C = \varepsilon_0\frac{S}{d} = 8,85\times10^{-12}\times\frac{100\times10^{-4}}{10^{-3}} = 8,85\times10^{-11} \text{ F}$. 2) $Q = CU = 8,85\times10^{-11}\times200 = 1,77\times10^{-8} \text{ C}$ ; $E = \frac{1}{2}CU^2 = \frac{1}{2}\times8,85\times10^{-11}\times4\times10^4 = 1,77\times10^{-6} \text{ J}$. 3) La capacité est multipliée par $\varepsilon_r = 4$.

**Exercice 7.** 1) $\frac{1}{R_{eq}} = \frac{1}{20}+\frac{1}{30}+\frac{1}{60} = \frac{3+2+1}{60} = \frac{6}{60} \Rightarrow R_{eq} = 10 \ \Omega$. 2) $I = \frac{U}{R_{eq}} = \frac{12}{10} = 1,2 \text{ A}$. 3) $I_1 = \frac{12}{20} = 0,6$ ; $I_2 = \frac{12}{30} = 0,4$ ; $I_3 = \frac{12}{60} = 0,2 \text{ A}$.

**Exercice 8.** 1) $B = \mu_0\frac{N}{l}I = 4\pi\times10^{-7}\times\frac{500}{0,5}\times4 = 5,03\times10^{-3} \text{ T}$. 2) Axe du solénoïde, sens donné par la règle de la main droite. 3) $e = L\frac{di}{dt} = 0,05\times\frac{4}{0,1} = 2 \text{ V}$.

**Exercice 9.** 1) $\tau = RC = 1000\times20\times10^{-6} = 0,02 \text{ s}$. 2) $u_C(t) = E(1 - e^{-t/\tau}) = 5(1 - e^{-t/0,02})$. 3) $u_C(2\tau) = 5(1 - e^{-2}) = 5\times0,865 = 4,32 \text{ V}$.

**Exercice 10.** 1) $u_r = ri = 10(2\times4 + 6) = 10\times14 = 140 \text{ V}$. 2) $e_L = L\frac{di}{dt}$ ; $\frac{di}{dt} = 4t + 3 = 11 \text{ A/s}$ à $t=2$ ; $e_L = 0,2\times11 = 2,2 \text{ V}$. 3) $u = ri + L\frac{di}{dt} = 140 + 2,2 = 142,2 \text{ V}$.

**Exercice 11.** 1) Fondamentale : $L = \frac{\lambda}{2} \Rightarrow \lambda = 2L = 2,4 \text{ m}$. 2) $v = \lambda f_1 = 2,4\times250 = 600 \text{ m/s}$. 3) $f_3 = 3f_1 = 750 \text{ Hz}$.

**Exercice 12.** 1) $\lambda = \frac{v}{f} = \frac{340}{680} = 0,5 \text{ m}$. 2) $d = vt = 340\times2 = 680 \text{ m}$. 3) Longitudinale (oscillation parallèle à la propagation). 4) $\lambda$ divisée par 2 : $\lambda = 0,25 \text{ m}$.

**Exercice 13.** 1) $\frac{1}{\overline{OA'}} = \frac{1}{f'} + \frac{1}{\overline{OA}} = \frac{1}{-20} + \frac{1}{-60} = -\frac{1}{20} - \frac{1}{60} = -\frac{4}{60} \Rightarrow \overline{OA'} = -15 \text{ cm}$. 2) $\gamma = \frac{\overline{OA'}}{\overline{OA}} = \frac{-15}{-60} = 0,25$. 3) Image virtuelle ($\overline{OA'} < 0$), droite ($\gamma > 0$), réduite ($\gamma < 1$).

**Exercice 14.** 1) $\sin r = \frac{\sin 60°}{1,6} = \frac{0,866}{1,6} = 0,541 \Rightarrow r = 32,8°$. 2) $d = 0,02\times\frac{\sin(27,2°)}{\cos 32,8°} = 0,02\times\frac{0,457}{0,840} = 0,0109 \text{ m} \approx 1,09 \text{ cm}$. 3) L'angle d'émergence = angle d'incidence (60°), la lame à faces parallèles ne dévie pas le rayon, le déplace seulement.

**Exercice 15.** 1) La largeur de la fente doit être de l'ordre de la longueur d'onde. 2) $\theta = \frac{\lambda}{a} = \frac{500\times10^{-9}}{0,1\times10^{-3}} = 5\times10^{-3} \text{ rad}$. 3) Largeur totale $= 2\theta D = 2\times5\times10^{-3}\times2 = 0,02 \text{ m}$.

**Exercice 16.** 1) $\lambda = \frac{\ln 2}{T} = \frac{0,693}{5,3} = 0,131 \text{ an}^{-1}$. 2) $A = A_0(1/2)^{10,6/5,3} = A_0(1/2)^2 = \frac{5\times10^{13}}{4} = 1,25\times10^{13} \text{ Bq}$. 3) $N_0 = \frac{A_0}{\lambda} = \frac{5\times10^{13}}{0,131} = 3,82\times10^{14}$ noyaux.

**Exercice 17.** 1) $f_0 = \frac{W_0}{h} = \frac{1,9\times1,6\times10^{-19}}{6,6\times10^{-34}} = 4,6\times10^{14} \text{ Hz}$. 2) $E = h\frac{c}{\lambda} = \frac{6,6\times10^{-34}\times3\times10^8}{400\times10^{-9}} = 4,95\times10^{-19} \text{ J} = 3,09 \text{ eV}$. 3) $E_c = 3,09 - 1,9 = 1,19 \text{ eV} > 0$ → oui, émission d'électrons.

**Exercice 18.** 1) Charge : $6 = 7 - 1$ ✓ ; masse : $14 = 14 + 0$ ✓. 2) $\frac{A}{A_0} = \frac{1}{8} = (1/2)^3$ → 3 demi-vies → $t = 3\times5730 = 17\,190$ ans. 3) Datation de fossiles et de matières organiques.

**Exercice 19.** 1) $\Delta m = (2,0141 + 3,0160) - (4,0026 + 1,0087) = 5,0301 - 5,0113 = 0,0188 \text{ u}$. 2) $E = 0,0188\times931,5 = 17,5 \text{ MeV}$. 3) La fusion dans le Soleil (les étoiles).

**Exercice 20.** 1) $E = 5,5\times1,6\times10^{-13} = 8,8\times10^{-13} \text{ J}$. 2) Noyaux d'hélium ($\phantom{}_{2}^{4}\text{He}$). 3) Pouvoir pénétrant faible (arrêtées par une feuille de papier), inférieur aux $\beta$ et $\gamma$. 4) Noyau fils : $A' = 234$, $Z' = 90$ (thorium).
