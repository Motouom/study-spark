## SECTION 1 : MÉCANIQUE

**Exercice 1 (5 points).** Un cycliste et son vélo (masse totale $m = 80 \text{ kg}$) roulent à la vitesse $v = 18 \text{ km/h}$ sur une route horizontale.

3. Calculer la quantité de mouvement. _(1 pt)_
4. Quelle force constante de freinage permettrait de l'arrêter sur 10 m ? _(1 pt)_

## CORRIGÉ

**Exercice 1.** 1) $v = \frac{18}{3,6} = 5 \text{ m/s}$. 2) $E_c = \frac{1}{2}\times80\times25 = 1000 \text{ J}$. 3) $p = mv = 80\times5 = 400 \text{ kg}\cdot\text{m/s}$. 4) $F = \frac{E_c}{d} = \frac{1000}{10} = 100 \text{ N}$.

**Exercice 2.** 1) $W(P) = -mgh = -600\times10\times15 = -90\,000 \text{ J}$. 2) $P = \frac{mgh}{t} = \frac{90\,000}{20} = 4\,500 \text{ W}$. 3) $v = \frac{h}{t} = \frac{15}{20} = 0,75 \text{ m/s}$.

**Exercice 3.** 1) $h_{max} = \frac{v_0^2}{2g} = \frac{900}{20} = 45 \text{ m}$. 2) $t_m = \frac{v_0}{g} = 3 \text{ s}$. 3) $h = v_0t - \frac{1}{2}gt^2 = 30\times2 - 5\times4 = 60 - 20 = 40 \text{ m}$.

**Exercice 4.** 1) $F = kx = 250\times0,08 = 20 \text{ N}$. 2) $m = \frac{F}{g} = \frac{20}{10} = 2 \text{ kg}$. 3) $E_p = \frac{1}{2}kx^2 = \frac{1}{2}\times250\times0,0064 = 0,8 \text{ J}$.

**Exercice 5.** 1) $P_{\parallel} = mg\sin\alpha = 1000\times10\times0,08 = 800 \text{ N}$. 2) $P = P_{\parallel}\times v = 800\times20 = 16\,000 \text{ W}$. 3) $W = P_{\parallel}\times100 = 80\,000 \text{ J}$.

**Exercice 6.** 1) $R_{eq} = 10+20+30 = 60 \ \Omega$. 2) $I = \frac{60}{60} = 1 \text{ A}$. 3) $U_1 = 10$ ; $U_2 = 20$ ; $U_3 = 30 \text{ V}$.

**Exercice 7.** 1) $Q = CU = 8\times10^{-6}\times250 = 2\times10^{-3} \text{ C}$. 2) $E = \frac{1}{2}CU^2 = \frac{1}{2}\times8\times10^{-6}\times62500 = 0,25 \text{ J}$. 3) Charge conservée : $Q_{tot} = 2\times10^{-3} = (C + C')U' \Rightarrow U' = \frac{2\times10^{-3}}{20\times10^{-6}} = 100 \text{ V}$.

**Exercice 8.** 1) $F = eE = 1,6\times10^{-19}\times2000 = 3,2\times10^{-16} \text{ N}$. 2) $a = \frac{F}{m_e} = \frac{3,2\times10^{-16}}{9,1\times10^{-31}} = 3,52\times10^{14} \text{ m/s}^2$. 3) $\frac{1}{2}mv^2 = eEd \Rightarrow d = \frac{\frac{1}{2}mv^2}{eE} = \frac{0,5\times9,1\times10^{-31}\times10^{12}}{3,2\times10^{-16}} = 1,42\times10^{-3} \text{ m}$.

**Exercice 9.** 1) $\omega_0 = 2\pi f_0 = 2\pi\times1000 = 6283 \text{ rad/s}$. 2) $C = \frac{1}{L\omega_0^2} = \frac{1}{0,05\times6283^2} = 5,07\times10^{-7} \text{ F}$. 3) À la résonance, $X_L = X_C$, les tensions réactives s'annulent, $Z = R$ minimale.

**Exercice 10.** 1) $e = Blv = 0,6\times0,4\times5 = 1,2 \text{ V}$. 2) La variation du flux magnétique à travers le circuit induit une force électromotrice (loi de Faraday). 3) Alternateurs, transformateurs, dynamos, plaques de cuisson à induction.

**Exercice 11.** 1) $f = \frac{v}{\lambda} = \frac{4}{0,5} = 8 \text{ Hz}$ ; $T = \frac{1}{8} = 0,125 \text{ s}$. 2) $n = \frac{10}{0,125} = 80$ oscillations. 3) $d = vt = 4\times3 = 12 \text{ m}$.

**Exercice 12.** 1) $\frac{1}{\overline{OA'}} = \frac{1}{15} + \frac{1}{-20} = \frac{1}{15} - \frac{1}{20} = \frac{1}{60} \Rightarrow \overline{OA'} = 60 \text{ cm}$. 2) $\gamma = \frac{60}{-20} = -3$ ; taille $= 3\times4 = 12 \text{ cm}$. 3) Image réelle ($\overline{OA'} > 0$), renversée ($\gamma < 0$).

**Exercice 13.** 1) $n_1\sin i = n_2\sin r$. 2) $\sin r = \frac{\sin 30°}{1,5} = \frac{0,5}{1,5} = 0,333 \Rightarrow r = 19,5°$. 3) $\sin i_c = \frac{1}{1,5} = 0,667 \Rightarrow i_c = 41,8°$ ; au-delà, réflexion totale.

**Exercice 14.** 1) $a = \frac{\lambda D}{i} = \frac{500\times10^{-9}\times1,5}{1,5\times10^{-3}} = 5\times10^{-4} \text{ m} = 0,5 \text{ mm}$. 2) Frange sombre 5 : $x = (k+\frac{1}{2})i$ avec $k=4$ : $x = 4,5\times1,5 = 6,75 \text{ mm}$. 3) Interférences constructives (différence de marche multiple de $\lambda$) → brillant ; destructives (demi-multiple) → sombre.

**Exercice 15.** 1) $\gamma = \frac{\overline{OA'}}{\overline{OA}} = -3$ ; $\overline{OA} = \frac{45}{-3} = -15 \text{ cm}$ (objet à 15 cm devant). 2) $\frac{1}{f'} = \frac{1}{45} - \frac{1}{-15} = \frac{1}{45} + \frac{1}{15} = \frac{4}{45} \Rightarrow f' = 11,25 \text{ cm}$. 3) $V = \frac{1}{0,1125} = 8,9 \ \delta$.

**Exercice 16.** 1) $\frac{A}{A_0} = \frac{1}{4} = (1/2)^2$ → 2 demi-vies. 2) $T = \frac{30}{2} = 15 \text{ jours}$. 3) $\lambda = \frac{0,693}{15} = 0,0462 \text{ jour}^{-1}$.

**Exercice 17.** 1) $E = h\frac{c}{\lambda} = \frac{6,6\times10^{-34}\times3\times10^8}{250\times10^{-9}} = 7,92\times10^{-19} \text{ J} = 4,95 \text{ eV}$. 2) $E_c = 4,95 - 3 = 1,95 \text{ eV}$. 3) Pour $\lambda = 600 \text{ nm}$ : $E = \frac{6,6\times10^{-34}\times3\times10^8}{600\times10^{-9}} = 3,3\times10^{-19} \text{ J} = 2,06 \text{ eV} < 3 \text{ eV}$ → pas d'effet photoélectrique.

**Exercice 18.** 1) A : $235 + 1 = 141 + 92 + 3 = 236$ ✓ ; Z : $92 = 56 + 36 = 92$ ✓. 2) $E = 0,19\times931,5 = 177 \text{ MeV}$. 3) 1 g contient $\frac{6,02\times10^{23}}{235} = 2,56\times10^{21}$ noyaux ; $E_{total} = 2,56\times10^{21}\times177 \text{ MeV} = 4,53\times10^{23} \text{ MeV}$.

**Exercice 19.** 1) $N = N_0(1/2)^2 = \frac{10^{20}}{4} = 2,5\times10^{19}$. 2) Désintégrés : $10^{20} - 2,5\times10^{19} = 7,5\times10^{19}$. 3) $\lambda = \frac{0,693}{8} = 0,0866 \text{ jour}^{-1}$ ; $A_0 = \lambda N_0 = 0,0866\times10^{20} = 8,66\times10^{18} \text{ Bq}$.

**Exercice 20.** 1) $\phantom{}_{38}^{90}\text{Sr} \rightarrow \phantom{}_{39}^{90}\text{Y} + \phantom{}_{-1}^{0}e + \bar{\nu}$. 2) $\lambda = \frac{0,693}{28} = 0,0248 \text{ an}^{-1}$. 3) $A_0 = \lambda N_0 = 0,0248\times10^{20} = 2,48\times10^{18} \text{ Bq}$ ; après 56 ans (2 demi-vies), $A = \frac{A_0}{4} = 6,2\times10^{17} \text{ Bq}$.
