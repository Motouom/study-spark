# Fiche de révision — Électricité et magnétisme (Terminale)

## Lois fondamentales

- Loi d'Ohm : $U = RI$
- Intensité : $I = \frac{\Delta Q}{\Delta t}$
- Générateur : $U_{PN} = E - rI$
- Loi des nœuds : $\sum I_{entrant} = \sum I_{sortant}$
- Loi des mailles : $\sum U = 0$
- Puissance : $P = UI = RI^2 = \frac{U^2}{R}$ ; $P_{tot} = EI$, $P_{utile} = UI$

## Résistances

- Série : $R_{eq} = R_1 + R_2 + \dots$
- Parallèle : $\frac{1}{R_{eq}} = \frac{1}{R_1} + \frac{1}{R_2} + \dots$

## Condensateurs et circuits RC

- Charge : $Q = CU$ ; énergie : $E = \frac{1}{2}CU^2$
- Série : $\frac{1}{C_{eq}} = \frac{1}{C_1} + \frac{1}{C_2}$ ; Parallèle : $C_{eq} = C_1 + C_2$
- Constante de temps : $\tau = RC$
- Charge : $u_C = E(1 - e^{-t/\tau})$ ; Décharge : $u_C = U_0 e^{-t/\tau}$

## Bobines et circuits RL

- Tension aux bornes : $u_L = ri + L\frac{di}{dt}$
- Constante de temps : $\tau = \frac{L}{R}$
- Établissement : $i = \frac{E}{R}(1 - e^{-t/\tau})$ ; régime permanent : $I_0 = \frac{E}{R}$

## Circuits RLC

- Pulsation propre : $\omega_0 = \frac{1}{\sqrt{LC}}$
- Fréquence propre : $f_0 = \frac{\omega_0}{2\pi}$
- Résonance d'intensité : $\omega = \omega_0$, $Z = R$ (courant maximal)

## Magnétisme

- Solénoïde : $B = \mu_0\frac{N}{l}I$ ($\mu_0 = 4\pi\times10^{-7}$ SI)
- Force de Lorentz : $F = qvB\sin\theta$ ; rayon $R = \frac{mv}{qB}$
- Force de Laplace : $F = BIl\sin\theta$
- Induction : $e = -\frac{d\Phi}{dt}$ ; tige : $e = Blv$
- Transformateur : $\frac{U_2}{U_1} = \frac{N_2}{N_1}$ ; $U_1I_1 = U_2I_2$

## Unités et préfixes

- Tension : V ; Courant : A ; Résistance : $\Omega$ ; Capacité : F ; Inductance : H ; Champ : T ; Flux : Wb
- $\mu = 10^{-6}$ ; $\text{m} = 10^{-3}$ ; $\text{k} = 10^3$

## Rappels de charge

- $e = 1,6\times10^{-19}$ C ; $k = 9\times10^9$ SI ; loi de Coulomb : $F = k\frac{|q_1q_2|}{d^2}$

## Conseils pour l'examen

1. Identifier si le montage est série ou parallèle.
2. À la résonance, penser $Z = R$.
3. Respecter les conventions générateur/récepteur.
4. Convertir les préfixes ($\mu\text{F}$, $\text{mH}$).
5. Pour les courbes $u_C(t)$ ou $i(t)$, utiliser la constante de temps $\tau$.
