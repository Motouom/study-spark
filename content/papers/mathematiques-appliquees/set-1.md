## CORRIGÉ TYPE

**Q1.** $f'(x) = 3x^2 - 6x = 3x(x-2)$. Zéros : x=0, x=2. f croissante sur ]−∞,0] et [2,+∞[, décroissante sur [0,2]. Maximum local f(0)=2, minimum local f(2)=−2.

**Q2.** $\lim_{x \to +\infty} \frac{2x^2 + 3x}{x^2 - 1} = \lim \frac{2x^2}{x^2} = 2$.

**Q3.** $g'(x) = \frac{2x}{x^2 + 1}$ (dérivée de ln(u) = u'/u).

**Q4.** $h'(x) = 2e^{2x}\sin(x) + e^{2x}\cos(x) = e^{2x}(2\sin x + \cos x)$ (produit).

**Q5.** $f'(x) = 2x$, $f'(1) = 2$, $f(1) = 1$. Tangente : $y = 2(x-1) + 1 = 2x - 1$.

**Q6.** $\int_0^1 (3x^2 + 2x) dx = [x^3 + x^2]_0^1 = 1 + 1 = 2$.

**Q7.** $\int_1^2 \frac{1}{x} dx = [\ln x]_1^2 = \ln 2$.

**Q8.** $\int_0^1 e^x dx = [e^x]_0^1 = e - 1$.

**Q9.** Aire = $\int_0^2 x^2 dx = [x^3/3]_0^2 = 8/3$.

**Q10.** Si F est une primitive de f, alors $\int_a^b f(x) dx = F(b) - F(a)$. L'intégration est l'inverse de la dérivation.

**Q11.** Expérience aléatoire : dont le résultat dépend du hasard. Univers : ensemble des résultats possibles. Événement : sous-ensemble de l'univers. Probabilité : mesure entre 0 et 1.

**Q12.** Univers {1,2,3,4,5,6}, pairs {2,4,6}. P = 3/6 = 1/2.

**Q13.** $P(A|B) = P(A \cap B) / P(B)$ : probabilité de A sachant que B est réalisé.

**Q14.** E(X) = 1×0,2 + 2×0,3 + 3×0,5 = 0,2 + 0,6 + 1,5 = 2,3.

**Q15.** Loi binomiale : n épreuves indépendantes, 2 issues (succès/échec), probabilité p constante. $P(X=k) = C_n^k p^k (1-p)^{n-k}$.

**Q16.** Moyenne : somme/valeurs. Médiane : valeur centrale. Mode : valeur la plus fréquente. Variance : moyenne des carrés des écarts. Écart-type : racine de la variance.

**Q17.** Moyenne = (10+12+14+16+18)/5 = 70/5 = 14.

**Q18.** Moyenne = 5. Variance = [(2−5)²+(4−5)²+(6−5)²+(8−5)²]/4 = (9+1+1+9)/4 = 20/4 = 5. Écart-type = √5 ≈ 2,24.

**Q19.** Descriptive : décrit les données (tableaux, graphiques, indicateurs). Inférentielle : tire des conclusions sur une population à partir d'un échantillon.

**Q20.** Le coefficient de corrélation (r entre −1 et 1) mesure la force du lien linéaire entre deux variables. r proche de ±1 = forte corrélation.

**Q21.** Suite arithmétique : $u_{n+1} = u_n + r$ (raison r). Suite géométrique : $u_{n+1} = u_n \times q$ (raison q).

**Q22.** $u_n = u_1 + (n-1)r = 2 + 9×3 = 2 + 27 = 29$.

**Q23.** $S_n = n(u_1 + u_n)/2 = 10(2 + 29)/2 = 10×31/2 = 155$.

**Q24.** $u_n = u_1 \times q^{n-1} = 2 × 2^4 = 2 × 16 = 32$.

**Q25.** La limite d'une suite est la valeur vers laquelle les termes tendent quand n tend vers l'infini. Si la suite converge, elle a une limite finie.
