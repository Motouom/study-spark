## CORRIGÉ TYPE

**Q1.** Posons $X = e^x$. $X^2 - 3X + 2 = 0 \iff X = 1$ ou $X = 2$. Donc $e^x = 1 \iff x = 0$, ou $e^x = 2 \iff x = \ln 2$. Solutions : x=0, x=ln 2.

**Q2.** $\ln(x+1) = 1 \iff x+1 = e \iff x = e - 1$.

**Q3.** $\ln(e^3) = 3$.

**Q4.** $f'(x) = e^{-x} - x e^{-x} = e^{-x}(1 - x)$. f croissante sur ]−∞,1], décroissante sur [1,+∞[. Maximum f(1) = 1/e.

**Q5.** $\lim_{x \to +\infty} x e^{-x} = \lim \frac{x}{e^x} = 0$ (l'exponentielle domine).

**Q6.** $f'(x) = \frac{2x + 2}{x^2 + 2x} = \frac{2(x+1)}{x(x+2)}$.

**Q7.** $g'(x) = \frac{e^x \cdot x - e^x \cdot 1}{x^2} = \frac{e^x(x-1)}{x^2}$.

**Q8.** $f'(x) = 2x - 4 = 0 \iff x = 2$. $f(2) = 4 - 8 + 7 = 3$. Minimum : (2, 3).

**Q9.** $f'(x) = e^{-x}(1-x) = 0 \iff x = 1$.

**Q10.** On exprime la quantité à optimiser en fonction d'une variable, on dérive, on annule la dérivée, on vérifie le signe. Ex : aire d'un rectangle de périmètre fixé → maximum pour le carré.

**Q11.** $\int_1^e \frac{1}{x} dx = [\ln x]_1^e = \ln e - \ln 1 = 1$.

**Q12.** $\int x e^x dx = x e^x - \int e^x dx = x e^x - e^x = e^x(x-1)$. De 0 à 1 : $e(0) - (1)(-1) = 0 + 1 = 1$. Résultat : 1.

**Q13.** $\int_0^2 (x^2 - 1) dx = [x^3/3 - x]_0^2 = 8/3 - 2 = 2/3$.

**Q14.** Valeur moyenne = $\frac{1}{2-0}\int_0^2 x dx = \frac{1}{2}[x^2/2]_0^2 = \frac{1}{2} \times 2 = 1$.

**Q15.** L'aire entre deux courbes f et g sur [a,b] est $\int_a^b |f(x) - g(x)| dx$. On intègre la différence des fonctions.

**Q16.** Variable aléatoire continue : prend une infinité de valeurs. Densité : fonction f ≥ 0 telle que $P(a \le X \le b) = \int_a^b f(x) dx$.

**Q17.** Loi uniforme sur [0,1] : densité f(x)=1 sur [0,1], 0 ailleurs. $P(a \le X \le b) = b - a$.

**Q18.** $P(X \le 0,5) = 0,5 - 0 = 0,5$.

**Q19.** Loi exponentielle de paramètre λ : densité $f(x) = \lambda e^{-\lambda x}$. Modélise les durées de vie sans vieillissement (mémoire sans âge). $P(X > t) = e^{-\lambda t}$.

**Q20.** $P(X \le 1) = 1 - e^{-1} = 1 - 1/e \approx 0,632$.

**Q21.** Série ordonnée de 5 valeurs : médiane = 3e valeur = 7.

**Q22.** 6 valeurs : Q1 = 2e valeur = 4 (position n/4 = 1,5 → 2e valeur).

**Q23.** Point fixe : $l = 0,5 l + 1 \iff l = 2$. $u_n = 2 - 2(0,5)^n$. $\lim u_n = 2$ (converge vers 2).

**Q24.** Somme infinie = $a/(1-q) = 1/(1 - 1/2) = 1/(1/2) = 2$.

**Q25.** Un point fixe l vérifie $l = f(l)$. Si la suite converge, sa limite est un point fixe de la fonction de récurrence.
