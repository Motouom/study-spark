## SECTION A : APPLICATIONS (intérêts, emprunts, optimisation)

**Exercice A1.** Un commerçant place un capital de 1 200 000 FCFA à intérêts composés au taux annuel de 6%.

1. Calculer la valeur acquise après 4 ans (arrondir au franc).
2. Après combien d'années le capital aura-t-il doublé ? (donner l'entier le plus proche).
3. Calculer le montant total des intérêts produits sur cette période.

**Exercice A2.** Une entreprise emprunte 5 000 000 FCFA, remboursable par 6 annuités constantes au taux annuel de 7%.

1. Calculer le montant de l'annuité constante $a$.
2. Établir le tableau d'amortissement des deux premières lignes (intérêt, amortissement, capital restant).
3. Interpréter pourquoi l'amortissement augmente d'une année à l'autre.

**Exercice A3.** La recette totale d'une entreprise est $R(x) = 80x$ et le coût total $C(x) = x^3 - 12x^2 + 60x + 200$, où $x$ est la quantité produite en centaines d'unités.

1. Déterminer le coût marginal $C'(x)$ et la recette marginale $R'(x)$.
2. Déterminer la production $x_0$ qui maximise le bénéfice.
3. Calculer le bénéfice maximal.

**Exercice A4.** Un producteur de cacao fait face à une fonction de demande $p(x) = 200 - 4x$ (prix en FCFA pour $x$ centaines de kg).

1. Exprimer la recette $R(x)$.
2. Calculer la quantité $x$ qui maximise la recette et le prix correspondant.
3. Déterminer l'élasticité de la demande en ce point et l'interpréter.

**Exercice A5.** Un champ rectangulaire de périmètre 200 m doit avoir une aire maximale.

1. Exprimer l'aire $A(x)$ en fonction d'un côté $x$.
2. Déterminer la valeur de $x$ qui maximise l'aire.
3. Donner les dimensions et l'aire maximale du champ.

## CORRIGÉ

### SECTION A

**A1.** 1. $V = 1\,200\,000 \times (1,06)^4$. Calcul : $1,06^4 = 1,26247696$ ; $V = 1\,200\,000 \times 1,26247696 = 1\,514\,972$ FCFA. 2. On cherche $n$ tel que $1,06^n = 2$. $\ln 1,06^n = \ln 2$ donc $n = \frac{\ln 2}{\ln 1,06} = \frac{0,6931}{0,0583} \approx 11,9$, soit **12 ans**. 3. Intérêts $= V - C = 1\,514\,972 - 1\,200\,000 = 314\,972$ FCFA.

**A2.** 1. Annuité : $a = C \frac{i}{1-(1+i)^{-n}} = 5\,000\,000 \times \frac{0,07}{1-(1,07)^{-6}}$. $(1,07)^{-6} = 0,666342$ ; $a = 5\,000\,000 \times \frac{0,07}{0,333658} = 5\,000\,000 \times 0,20979 = 1\,048\,950$ FCFA. 2. Ligne 1 : intérêt $= 5\,000\,000 \times 0,07 = 350\,000$ ; amortissement $= 1\,048\,950 - 350\,000 = 698\,950$ ; capital restant $= 5\,000\,000 - 698\,950 = 4\,301\,050$. Ligne 2 : intérêt $= 4\,301\,050 \times 0,07 = 301\,073,5$ ; amortissement $= 1\,048\,950 - 301\,073,5 = 747\,876,5$ ; capital restant $= 4\,301\,050 - 747\,876,5 = 3\,553\,173,5$. 3. L'intérêt diminue car le capital restant diminue ; l'annuité étant constante, l'amortissement augmente.

**A3.** 1. $C'(x) = 3x^2 - 24x + 60$ ; $R'(x) = 80$. 2. Bénéfice $B = R - C$ ; $B' = R' - C' = 80 - (3x^2 - 24x + 60) = -3x^2 + 24x + 20$. $B' = 0 \Leftrightarrow 3x^2 - 24x - 20 = 0$ ; $\Delta = 576 + 240 = 816$ ; $x = \frac{24 \pm \sqrt{816}}{6} = \frac{24 \pm 28,57}{6}$. La solution positive est $x_0 = \frac{24+28,57}{6} \approx 8,76$ (en centaines d'unités), soit environ 876 unités. 3. Bénéfice maximal : $B(8,76) = 80(8,76) - [8,76^3 - 12(8,76)^2 + 60(8,76) + 200]$. $8,76^3 = 672,1$ ; $12 \times 76,7 = 920,5$ ; $C = 672,1 - 920,5 + 525,6 + 200 = 477,2$ ; $R = 700,8$ ; $B \approx 223,6$ (en milliers), soit environ 223 600 FCFA.

**A4.** 1. $R(x) = x(200 - 4x) = 200x - 4x^2$. 2. $R'(x) = 200 - 8x = 0$ donne $x = 25$ ; prix $p = 200 - 4 \times 25 = 100$ FCFA. Recette maximale $R = 25 \times 100 = 2\,500$. 3. Élasticité $\varepsilon = \frac{p'(x) \cdot x}{p(x)} = \frac{-4 \times 25}{100} = -1$. En ce point la demande est d'élasticité unitaire : une variation du prix provoque une variation proportionnellement inverse de la quantité, la recette étant stationnaire.

**A5.** 1. Périmètre $2(x + y) = 200$ donc $y = 100 - x$ ; aire $A(x) = x(100 - x) = 100x - x^2$. 2. $A'(x) = 100 - 2x = 0$ donne $x = 50$. 3. Dimensions $50$ m × $50$ m (carré) ; aire maximale $= 50 \times 50 = 2\,500$ m².

### SECTION B

**B1.** 1. $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$ ; $f' \geq 0$ sur $]-\infty,-1] \cup [1,+\infty[$, $f' \leq 0$ sur $[-1,1]$. 2. Maximum local $f(-1) = -1 + 3 + 2 = 4$ ; minimum local $f(1) = 1 - 3 + 2 = 0$ ; croissante puis décroissante puis croissante. 3. $f(x) = 0 \Leftrightarrow x^3 - 3x + 2 = 0$ ; on note que $x=1$ est racine : $(x-1)(x^2+x-2) = (x-1)(x-1)(x+2)$, racines $x=1$ (double) et $x=-2$. Intersections : $(1,0)$ et $(-2,0)$.

**B2.** 1. $f$ définie sur $\mathbb{R} \setminus \{-1\}$. 2. $\lim_{x \to +\infty} \frac{x}{x+1} = 1$ ; $\lim_{x \to -\infty} \frac{x}{x+1} = 1$ ; $\lim_{x \to -1^+} f = +\infty$ et $\lim_{x \to -1^-} f = -\infty$. 3. $f'(x) = \frac{(x+1) - x}{(x+1)^2} = \frac{1}{(x+1)^2} > 0$ : $f$ strictement croissante sur chaque intervalle. $f(x) - 1 = \frac{x}{x+1} - 1 = -\frac{1}{x+1}$ : la courbe est au-dessus de $y=1$ pour $x < -1$ et en dessous pour $x > -1$.

**B3.** 1. $\mathcal{D}_f = ]0, +\infty[$ ; $f'(x) = \frac{1}{x}$. 2. $f(1) = 0$, $f'(1) = 1$ ; tangente $y = x - 1$. 3. $\int_1^e \ln x \, dx$. Une primitive de $\ln x$ est $x\ln x - x$ ; en $e$ : $e - e = 0$ ; en $1$ : $0 - 1 = -1$ ; aire $= 0 - (-1) = 1$ (u.a.).

**B4.** 1. $f'(x) = 2e^{2x}$ ; $f''(x) = 4e^{2x}$. 2. $e^{2x} > 0$ donc $f' > 0$ : $f$ strictement croissante sur $\mathbb{R}$. 3. $\int_0^1 e^{2x} dx = \left[\frac{1}{2}e^{2x}\right]_0^1 = \frac{1}{2}(e^2 - 1)$.

**B5.** 1. $-(x-1)(x-3) = -(x^2 - 4x + 3) = -x^2 + 4x - 3 = f(x)$. 2. $f'(x) = -2x + 4$ ; $f'=0 \Leftrightarrow x=2$ ; maximum $f(2) = -4 + 8 - 3 = 1$. 3. $\int_1^3 f(x) dx = \left[-\frac{x^3}{3} + 2x^2 - 3x\right]_1^3$. En 3 : $-9 + 18 - 9 = 0$ ; en 1 : $-\frac{1}{3} + 2 - 3 = -\frac{4}{3}$ ; intégrale $= 0 - (-\frac{4}{3}) = \frac{4}{3}$ (u.a.).

### SECTION C

**C1.** 1. $\Delta = 25 - 24 = 1$ ; $x = \frac{5\pm 1}{2}$ : $x = 2$ et $x = 3$. 2. $x(x^2 - 4) = x(x-2)(x+2) = 0$ : $x = 0$, $x=2$, $x=-2$. 3. $x^2 - 4x + 4 = (x-2)^2 \leq 0$ : l'unique solution est $x = 2$.

**C2.** 1. De $x + 2y = 5$ on tire $x = 5 - 2y$ ; dans $3x - y = 1$ : $3(5-2y) - y = 1 \Rightarrow 15 - 6y - y = 1 \Rightarrow -7y = -14 \Rightarrow y = 2$ ; $x = 5 - 4 = 1$. 2. Par combinaison : multiplier la 1re par 3 : $3x+6y = 15$ ; soustraire $3x - y = 1$ : $7y = 14$, $y = 2$ ; $x = 1$. 3. Les deux droites sont sécantes en $(1,2)$.

**C3.** 1. $u_n = u_0 + nr = 2 + 3n$. 2. $u_{10} = 2 + 30 = 32$. 3. $S = \frac{(n+1)(u_0 + u_{10})}{2} = \frac{11(2+32)}{2} = 187$.

**C4.** 1. $v_n = v_0 q^n = 5 \times 2^n$. 2. $v_6 = 5 \times 64 = 320$. 3. $S = v_0 \frac{1 - q^{n+1}}{1-q} = 5 \times \frac{1 - 2^7}{1-2} = 5 \times \frac{1-128}{-1} = 5 \times 127 = 635$.

**C5.** 1. $w_1 = 0,5 \times 0 + 4 = 4$ ; $w_2 = 0,5 \times 4 + 4 = 6$ ; $w_3 = 0,5 \times 6 + 4 = 7$. 2. $w_{n+1} - 8 = 0,5 w_n + 4 - 8 = 0,5(w_n - 8)$ : donc $(w_n - 8)$ est géométrique de raison $0,5$ et premier terme $w_0 - 8 = -8$. 3. $w_n - 8 = -8 \times 0,5^n$ donc $w_n = 8 - 8 \times 0,5^n$ ; comme $0,5^n \to 0$, $w_n \to 8$.

### SECTION D

**D1.** Total 8 boules. 1. $P(RR) = \frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14}$. 2. $P(BB) = \frac{3}{8} \times \frac{2}{7} = \frac{6}{56} = \frac{3}{28}$. 3. $P(\text{même couleur}) = \frac{5}{14} + \frac{3}{28} = \frac{10}{28} + \frac{3}{28} = \frac{13}{28}$.

**D2.** 1. $E(X) = np = 4$ ; $V(X) = np(1-p) = 2,4$. 2. $P(X=3) = \binom{10}{3}(0,4)^3(0,6)^7 = 120 \times 0,064 \times 0,02799 = 0,215$. 3. $P(X \geq 1) = 1 - P(X=0) = 1 - (0,6)^{10} = 1 - 0,0060 = 0,994$.

**D3.** 1. $\bar{x} = 6$. 2. Variance $= 8$ ; écart-type $\sigma = \sqrt{8} \approx 2,83$. 3. Médiane $= 6$ ; étendue $= 10 - 2 = 8$.

**D4.** 1. $P(A \cap B) = 0,3 \times 0,5 = 0,15$. 2. $P(A \cup B) = 0,3 + 0,5 - 0,15 = 0,65$. 3. $P(A \mid B) = \frac{P(A\cap B)}{P(B)} = \frac{0,15}{0,5} = 0,3 = P(A)$, cohérent avec l'indépendance.

**D5.** 1. $P(40 \leq X \leq 60) = P(\mu - \sigma \leq X \leq \mu + \sigma) \approx 0,68$ (règle empirique). 2. Par symétrie, $P(X \leq 50) = 0,5$. 3. $Z = \frac{X - 50}{10}$ ; pour $x = 60$, $z = \frac{60-50}{10} = 1$.
