## SECTION A : APPLICATIONS (intérêts, emprunts, optimisation)

**Exercice A1.** Une épargnante place 1 500 000 FCFA à intérêts composés au taux annuel de 5,5%.

1. Calculer la valeur acquise après 6 ans (au franc près).
2. Déterminer le nombre d'années pour que le capital augmente de 50%.
3. Calculer le montant des intérêts la 4e année (différence entre valeur acquise à 4 ans et à 3 ans).

**Exercice A2.** Un commerçant emprunte 8 000 000 FCFA, remboursables par 5 annuités constantes au taux annuel de 8%.

1. Calculer l'annuité constante $a$.
2. Établir le tableau d'amortissement des deux premières lignes.
3. Calculer le capital restant dû après 3 annuités.

**Exercice A3.** Une entreprise produit $x$ milliers d'articles avec un coût total $C(x) = x^3 - 9x^2 + 40x + 50$ (en milliers de FCFA) et une recette $R(x) = 25x$.

1. Déterminer la fonction bénéfice $B(x)$.
2. Étudier le sens de variation de $B$ sur $[0, 8]$.
3. Déterminer la production qui maximise le bénéfice et le bénéfice maximal.

**Exercice A4.** Un exploitant a une fonction de coût moyen $C_m(x) = x + 5 + \frac{36}{x}$.

1. Déterminer le minimum du coût moyen et la production correspondante.
2. Vérifier l'égalité coût moyen / coût marginal en ce point.
3. Interpréter ce point dans un contexte économique.

**Exercice A5.** La fonction de demande d'un bien est $p(x) = 400 - 2x$.

1. Exprimer la recette $R(x)$ et déterminer la recette maximale.
2. Calculer l'élasticité de la demande au point $x = 50$.
3. Interpréter le signe de l'élasticité.

## CORRIGÉ

### SECTION A

**A1.** 1. $V = 1\,500\,000 \times (1,055)^6$ ; $1,055^6 = 1,37884$ ; $V = 2\,068\,260$ FCFA. 2. $1,055^n = 1,5$ : $n = \frac{\ln 1,5}{\ln 1,055} = \frac{0,4055}{0,0535} = 7,57$, soit **8 ans**. 3. $V_4 = 1\,500\,000 \times 1,055^4 = 1\,500\,000 \times 1,23882 = 1\,858\,230$ ; $V_3 = 1\,500\,000 \times 1,055^3 = 1\,500\,000 \times 1,17424 = 1\,761\,360$ ; intérêts de la 4e année $= 1\,858\,230 - 1\,761\,360 = 96\,870$ FCFA.

**A2.** 1. $a = 8\,000\,000 \times \frac{0,08}{1-(1,08)^{-5}}$. $(1,08)^{-5} = 0,680583$ ; $a = 8\,000\,000 \times \frac{0,08}{0,319417} = 8\,000\,000 \times 0,25046 = 2\,003\,680$ FCFA. 2. Ligne 1 : intérêt $= 640\,000$ ; amortissement $= 2\,003\,680 - 640\,000 = 1\,363\,680$ ; capital restant $= 6\,636\,320$. Ligne 2 : intérêt $= 6\,636\,320 \times 0,08 = 530\,905,6$ ; amortissement $= 1\,472\,774,4$ ; capital restant $= 5\,163\,545,6$. 3. Capital restant $= a \frac{1-(1+i)^{-(n-k)}}{i}$ avec $n-k = 2$ : $2\,003\,680 \times \frac{1-(1,08)^{-2}}{0,08}$. $(1,08)^{-2} = 0,857339$ ; $= 2\,003\,680 \times \frac{0,142661}{0,08} = 2\,003\,680 \times 1,78326 = 3\,573\,300$ FCFA.

**A3.** 1. $B(x) = 25x - (x^3 - 9x^2 + 40x + 50) = -x^3 + 9x^2 - 15x - 50$. 2. $B'(x) = -3x^2 + 18x - 15 = -3(x^2 - 6x + 5) = -3(x-1)(x-5)$. Sur $[0,8]$ : $B' \geq 0$ sur $[1,5]$, $B' \leq 0$ sur $[0,1]$ et $[5,8]$. 3. $x = 5$ maximise $B$ ; $B(5) = -125 + 225 - 75 - 50 = -25$ (en milliers de FCFA). $B(1) = -1 + 9 - 15 - 50 = -57$. Le maximum sur $[0,8]$ est atteint en $x=5$ avec $B(5) = -25$.

**A4.** 1. $C_m'(x) = 1 - \frac{36}{x^2}$ ; $C_m' = 0 \Leftrightarrow x^2 = 36 \Leftrightarrow x = 6$ ; $C_m(6) = 6 + 5 + 6 = 17$. 2. $C(x) = x C_m(x) = x^2 + 5x + 36$ ; $C'(x) = 2x + 5$ ; $C'(6) = 12 + 5 = 17 = C_m(6)$. 3. Le minimum du coût moyen est atteint lorsque coût moyen = coût marginal : c'est le point de production optimale de l'entreprise à court terme.

**A5.** 1. $R(x) = x(400 - 2x) = 400x - 2x^2$ ; $R'(x) = 400 - 4x = 0 \Leftrightarrow x = 100$ ; $R(100) = 40000 - 20000 = 20000$. 2. Élasticité $\varepsilon = \frac{p'(x)x}{p(x)} = \frac{-2 \times 50}{400 - 100} = \frac{-100}{300} = -\frac{1}{3}$. 3. Élasticité négative : quand le prix augmente, la quantité demandée diminue (loi de la demande). Ici $|\varepsilon| = \frac{1}{3} < 1$ : demande inélastique.

### SECTION B

**B1.** 1. $f'(x) = 6x^2 - 6x - 12 = 6(x^2 - x - 2) = 6(x-2)(x+1)$. 2. $f' > 0$ sur $]-\infty,-1[ \cup ]2,+\infty[$, $f' < 0$ sur $]-1,2[$. 3. $f(-1) = -2 - 3 + 12 + 1 = 8$ (maximum local) ; $f(2) = 16 - 12 - 24 + 1 = -19$ (minimum local).

**B2.** 1. Définie sur $\mathbb{R}\setminus\{1\}$ ; $\lim_{\pm\infty} f = 3$ ; $\lim_{x\to1^+} f = +\infty$, $\lim_{x\to1^-} f = -\infty$. 2. $3 + \frac{1}{x-1} = \frac{3x-3+1}{x-1} = \frac{3x-2}{x-1}$. 3. $f'(x) = -\frac{1}{(x-1)^2} < 0$ : strictement décroissante sur chaque intervalle. Asymptotes $y = 3$ et $x = 1$.

**B3.** 1. $f'(x) = 3e^{3x}$ ; $f''(x) = 9e^{3x}$. 2. $f' > 0$ : strictement croissante sur $\mathbb{R}$. 3. $\int_0^2 e^{3x} dx = \left[\frac{1}{3}e^{3x}\right]_0^2 = \frac{1}{3}(e^6 - 1)$.

**B4.** 1. $x^2 - 4x + 3 = (x-1)(x-3)$. 2. $f > 0$ sur $]-\infty,1[ \cup ]3,+\infty[$, $f < 0$ sur $]1,3[$. 3. $\int_0^2 f(x) dx = \left[\frac{x^3}{3} - 2x^2 + 3x\right]_0^2 = \frac{8}{3} - 8 + 6 = \frac{8}{3} - 2 = \frac{2}{3}$.

**B5.** 1. $f'(x) = \frac{\frac{1}{x} \cdot x - \ln x}{x^2} = \frac{1 - \ln x}{x^2}$. 2. $f' = 0 \Leftrightarrow \ln x = 1 \Leftrightarrow x = e$ ; $f$ croît sur $]0,e[$, décroît sur $]e,+\infty[$ ; maximum $f(e) = \frac{1}{e}$. 3. $\lim_{x\to0^+} f = -\infty$ ; $\lim_{x\to+\infty} f = 0$.

### SECTION C

**C1.** 1. $\Delta = 100 - 36 = 64$ ; $x = \frac{10 \pm 8}{6}$ : $x = 3$ et $x = \frac{1}{3}$. 2. $x^2 - 4x + 13 = 0$ : $\Delta = 16 - 52 = -36 < 0$ : aucune solution réelle. 3. $x(x^2 - 6x + 9) = x(x-3)^2 = 0$ : $x = 0$ et $x = 3$ (double).

**C2.** 1. De $2x - 5y = 0$, $x = \frac{5y}{2}$ ; dans $4x + 3y = 26$ : $4(\frac{5y}{2}) + 3y = 26 \Rightarrow 10y + 3y = 26 \Rightarrow y = 2$ ; $x = 5$. 2. Multiplier la 2e par 2 : $4x - 10y = 0$ ; soustraire de la 1re : $13y = 26$, $y = 2$, $x = 5$. 3. Droites sécantes en $(5, 2)$.

**C3.** 1. $u_6 - u_2 = 26 - 10 = 16 = 4r$ donc $r = 4$ ; $u_2 = u_0 + 2(4) = 10 \Rightarrow u_0 = 2$. 2. $u_n = 2 + 4n$. 3. $S = \frac{16(u_0 + u_{15})}{2}$ ; $u_{15} = 2 + 60 = 62$ ; $S = \frac{16(2+62)}{2} = 512$.

**C4.** 1. $v_4 = v_1 q^3$ : $48 = 6 q^3 \Rightarrow q^3 = 8 \Rightarrow q = 2$ ; $v_1 = v_0 q = 2v_0 = 6 \Rightarrow v_0 = 3$. 2. $v_n = 3 \times 2^n$. 3. $S_9 = 3 \times \frac{1 - 2^{10}}{1-2} = 3 \times \frac{1-1024}{-1} = 3069$.

**C5.** 1. $u_1 = 3(1)+1 = 4$ ; $u_2 = 3(4)+1 = 13$ ; $u_3 = 3(13)+1 = 40$. 2. $u_{n+1} + \frac{1}{2} = 3u_n + 1 + \frac{1}{2} = 3u_n + \frac{3}{2} = 3(u_n + \frac{1}{2})$ : géométrique de raison 3, premier terme $u_0 + \frac{1}{2} = \frac{3}{2}$. 3. $u_n + \frac{1}{2} = \frac{3}{2} \times 3^n$ ; $u_n = \frac{3^{n+1}}{2} - \frac{1}{2}$ ; $\lim u_n = +\infty$.
