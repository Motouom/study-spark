# Fiche de révision — Analyse

## 1. Dérivées usuelles

- $(x^n)' = n x^{n-1}$
- $(k)' = 0$ ; $(x)' = 1$
- $(\frac{1}{x})' = -\frac{1}{x^2}$
- $(\sqrt{x})' = \frac{1}{2\sqrt{x}}$
- $(e^x)' = e^x$ ; $(e^{u})' = u' e^{u}$
- $(\ln x)' = \frac{1}{x}$ ; $(\ln u)' = \frac{u'}{u}$

## 2. Opérations de dérivation

- $(u + v)' = u' + v'$ ; $(k u)' = k u'$
- $(uv)' = u'v + uv'$
- $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$

## 3. Variations et extrema

- $f' \geq 0 \Rightarrow f$ croissante ; $f' \leq 0 \Rightarrow f$ décroissante.
- Extremum en $a$ si $f'(a) = 0$ et $f'$ change de signe.
- **Tangente en $a$ :** $y = f(a) + f'(a)(x-a)$.

## 4. Limites à connaître

- $\lim_{x\to+\infty} \frac{1}{x} = 0$ ; $\lim_{x\to+\infty} \frac{1}{x^n} = 0$
- $\lim_{x\to+\infty} e^x = +\infty$ ; $\lim_{x\to-\infty} e^x = 0$
- $\lim_{x\to+\infty} \ln x = +\infty$ ; $\lim_{x\to0^+} \ln x = -\infty$
- Fraction rationnelle : factoriser par le plus haut degré ; si degrés égaux, limite = rapport des coefficients dominants.
- Formes indéterminées : $\frac{\infty}{\infty}$, $0 \times \infty$, $\infty - \infty$ — lever en factorisant.

## 5. Primitives et intégrales

- $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$ ($n \neq -1$)
- $\int \frac{1}{x}\,dx = \ln|x| + C$
- $\int e^x\,dx = e^x + C$ ; $\int \frac{1}{x+1}$ (forme $\frac{u'}{u}$) $= \ln|u| + C$
- $\int_a^b f(x)\,dx = F(b) - F(a)$
- Aire sous la courbe (si $f \geq 0$) $= \int_a^b f(x)\,dx$

## 6. Applications économiques

- Coût marginal $C_m = C'(x)$ ; recette marginale $R_m = R'(x)$
- Bénéfice $B = R - C$ ; maximum quand $B' = 0 \Leftrightarrow R' = C'$
- Coût moyen $= \frac{C(x)}{x}$ ; minimisé quand coût moyen = coût marginal.

## 7. Réflexes à l'épreuve

1. Toujours commencer par l'ensemble de définition.
2. Dériver avant d'étudier les variations.
3. Pour un maximum/minimum, vérifier le signe de $f'$ des deux côtés.
4. Écrire toutes les étapes du calcul d'intégrale ($F(b) - F(a)$).
5. Vérifier les unités et encadrer le résultat final.
