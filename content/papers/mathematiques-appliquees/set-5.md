## SECTION A : APPLICATIONS (intérêts, emprunts, optimisation)

**Exercice A1.** Une commerçante place 800 000 FCFA à intérêts composés au taux annuel de 4,5%.

1. Calculer la valeur acquise après 3 ans (au franc près).
2. Calculer le taux équivalent mensuel.
3. En déduire la valeur acquise au bout de 36 mois avec ce taux mensuel et comparer.

**Exercice A2.** Un particulier emprunte 2 400 000 FCFA remboursables par 8 mensualités constantes au taux mensuel de 1,2%.

1. Calculer le montant de la mensualité $m$.
2. Calculer le coût total du crédit (intérêts totaux).
3. Donner le montant du capital restant dû après 4 mensualités.

**Exercice A3.** Une société a pour coût total $C(x) = 0,5x^2 + 3x + 500$ (en milliers de FCFA) pour $x$ unités produites, et vend chaque unité au prix unitaire de $25$ milliers de FCFA.

1. Déterminer la recette $R(x)$ et le bénéfice $B(x)$.
2. Déterminer la production qui maximise le bénéfice.
3. Calculer le bénéfice maximal et le seuil de rentabilité.

**Exercice A4.** Une entreprise souhaite minimiser le coût moyen $C_m(x) = \frac{C(x)}{x} = 2x + 10 + \frac{200}{x}$.

1. Déterminer le coût moyen minimal et la production correspondante.
2. Vérifier qu'en ce point le coût moyen est égal au coût marginal.
3. Interpréter économiquement ce résultat.

**Exercice A5.** Une fonction de production est $Q(L) = 30\sqrt{L}$, où $L$ est le nombre de travailleurs.

1. Calculer la productivité marginale $Q'(L)$.
2. Étudier le signe de $Q''(L)$ et conclure sur le rendement.
3. Calculer la productivité moyenne $\frac{Q(L)}{L}$ pour $L = 100$.

## SECTION D : PROBABILITÉS ET STATISTIQUES

**Exercice D1.** Une urne contient 4 boules rouges, 5 boules noires et 3 boules blanches. On tire une boule au hasard.

3. Calculer la probabilité de ne pas obtenir une boule noire.

**Exercice D2.** Dans un atelier, 60% des pièces sont produites par une machine A et 40% par une machine B. La machine A produit 2% de pièces défectueuses, la machine B 5%.

**Exercice D3.** La moyenne des notes d'une classe de 40 élèves est 12. La classe de 60 élèves voisine a une moyenne de 10.

**Exercice D4.** On lance une pièce de monnaie équilibrée 5 fois. Soit $X$ le nombre de faces obtenues.

**Exercice D5.** Une variable $X$ suit la loi normale $N(100 ; 15)$.

## CORRIGÉ

### SECTION A

**A1.** 1. $V = 800\,000 \times (1,045)^3$ ; $1,045^3 = 1,141166$ ; $V = 912\,933$ FCFA. 2. Taux équivalent mensuel $i_m$ : $(1+i_m)^{12} = 1,045$ donc $i_m = (1,045)^{1/12} - 1 = 1,003675 - 1 = 0,003675$, soit $0,3675\%$. 3. $V = 800\,000 \times (1,003675)^{36} = 800\,000 \times 1,141166 = 912\,933$ FCFA (on retrouve la même valeur).

**A2.** 1. $m = C \frac{i}{1-(1+i)^{-n}} = 2\,400\,000 \times \frac{0,012}{1-(1,012)^{-8}}$. $(1,012)^{-8} = 0,9090$ ; $m = 2\,400\,000 \times \frac{0,012}{0,0910} = 2\,400\,000 \times 0,13187 = 316\,488$ FCFA. 2. Total payé $= 8 \times 316\,488 = 2\,531\,904$ ; intérêts totaux $= 2\,531\,904 - 2\,400\,000 = 131\,904$ FCFA. 3. Capital restant $= m \frac{1-(1+i)^{-(n-k)}}{i}$ avec $n-k = 4$ : $316\,488 \times \frac{1-(1,012)^{-4}}{0,012}$. $(1,012)^{-4} = 0,9533$ ; $= 316\,488 \times \frac{0,0467}{0,012} = 316\,488 \times 3,8917 = 1\,231\,700$ FCFA.

**A3.** 1. $R(x) = 25x$ ; $B(x) = 25x - (0,5x^2 + 3x + 500) = -0,5x^2 + 22x - 500$. 2. $B'(x) = -x + 22 = 0$ donne $x = 22$ unités. 3. $B(22) = -0,5(484) + 484 - 500 = -242 + 484 - 500 = -258$ (en milliers) ; seuil de rentabilité : $B(x) = 0 \Leftrightarrow -0,5x^2 + 22x - 500 = 0 \Leftrightarrow x^2 - 44x + 1000 = 0$, $\Delta = 1936 - 4000 < 0$ : pas de seuil de rentabilité (le bénéfice reste négatif sur tout le domaine).

**A4.** 1. $C_m'(x) = 2 - \frac{200}{x^2}$ ; $C_m' = 0 \Leftrightarrow x^2 = 100 \Leftrightarrow x = 10$ ; $C_m(10) = 20 + 10 + 20 = 50$. 2. $C(x) = 2x^2 + 10x + 200$ donc $C'(x) = 4x + 10$ ; $C'(10) = 40 + 10 = 50 = C_m(10)$ : en $x = 10$ le coût moyen égale le coût marginal. 3. Économiquement, le coût moyen est minimal quand il est égal au coût marginal : c'est la production optimale à court terme.

**A5.** 1. $Q'(L) = 30 \times \frac{1}{2\sqrt{L}} = \frac{15}{\sqrt{L}}$. 2. $Q''(L) = -\frac{7,5}{L^{3/2}} < 0$ : productivité marginale décroissante, rendement décroissant. 3. Productivité moyenne $= \frac{30\sqrt{100}}{100} = \frac{300}{100} = 3$.

### SECTION B

**B1.** 1. $f(-x) = (-x)^4 - 8(-x)^2 + 7 = x^4 - 8x^2 + 7 = f(x)$ : $f$ est paire, sa courbe est symétrique par rapport à l'axe des ordonnées. 2. $f'(x) = 4x^3 - 16x = 4x(x^2 - 4) = 4x(x-2)(x+2)$ ; signe : négatif sur $]-\infty,-2[$, positif sur $]-2,0[$, négatif sur $]0,2[$, positif sur $]2,+\infty[$. Minima en $\pm 2$ ($f(\pm 2) = 16 - 32 + 7 = -9$), maximum local en $0$ ($f(0) = 7$). 3. $x^4 - 8x^2 + 7 = 0$ ; posons $X = x^2$ : $X^2 - 8X + 7 = 0$, $\Delta = 64-28 = 36$ ; $X = 1$ ou $X = 7$ ; donc $x = \pm 1$ et $x = \pm\sqrt{7}$.

**B2.** 1. Définie sur $\mathbb{R}\setminus\{1\}$. $\lim_{x\to\pm\infty} \frac{2x+1}{x-1} = 2$ ; $\lim_{x\to1^+} f = +\infty$, $\lim_{x\to1^-} f = -\infty$. 2. $2 + \frac{3}{x-1} = \frac{2(x-1)+3}{x-1} = \frac{2x+1}{x-1} = f(x)$. 3. $f'(x) = -\frac{3}{(x-1)^2} < 0$ : strictement décroissante sur chaque intervalle. Asymptotes : $y = 2$ (horizontale) et $x = 1$ (verticale).

**B3.** 1. Définie sur $]0,+\infty[$ ; $f'(x) = \ln x + x \cdot \frac{1}{x} = \ln x + 1$. 2. $f' = 0 \Leftrightarrow \ln x = -1 \Leftrightarrow x = e^{-1}$ ; minimum $f(e^{-1}) = e^{-1} \ln e^{-1} = -e^{-1}$. Décroissante sur $]0, e^{-1}[$, croissante sur $]e^{-1}, +\infty[$. 3. $\int_1^e x \ln x \, dx$ ; une primitive de $x\ln x$ est $\frac{x^2}{2}\ln x - \frac{x^2}{4}$ ; en $e$ : $\frac{e^2}{2} - \frac{e^2}{4} = \frac{e^2}{4}$ ; en 1 : $0 - \frac{1}{4} = -\frac{1}{4}$ ; intégrale $= \frac{e^2}{4} + \frac{1}{4} = \frac{e^2+1}{4}$.

**B4.** 1. $f'(x) = -e^{-x} < 0$ : strictement décroissante. 2. $\lim_{x\to-\infty} e^{-x} = +\infty$ ; $\lim_{x\to+\infty} e^{-x} = 0$. 3. $\int_0^1 e^{-x} dx = \left[-e^{-x}\right]_0^1 = -e^{-1} + 1 = 1 - \frac{1}{e}$.

**B5.** 1. Sommet en $x = \frac{12}{2 \times 3} = 2$ ; $f(2) = 12 - 24 + 5 = -7$ ; sommet $(2, -7)$. 2. $\Delta = 144 - 60 = 84$ ; racines $x = \frac{12 \pm \sqrt{84}}{6} = \frac{12 \pm 9,165}{6}$, soit $x_1 = 0,47$ et $x_2 = 3,53$ ; $f > 0$ hors des racines, $f < 0$ entre elles. 3. $\int_0^3 f(x) dx = \left[x^3 - 6x^2 + 5x\right]_0^3 = 27 - 54 + 15 = -12$.

### SECTION C

**C1.** 1. $\Delta = 9 + 16 = 25$ ; $x = \frac{-3 \pm 5}{4}$ : $x = \frac{1}{2}$ et $x = -2$. 2. $x^2 - 6x + 9 = (x-3)^2 = 0$ : $x = 3$ (double). 3. $3x^2 + 5x + 4 = 0$ : $\Delta = 25 - 48 = -23 < 0$ : aucune solution réelle (deux racines complexes conjuguées).

**C2.** 1. De $x + 4y = -2$, $x = -2 - 4y$ ; dans $2x - 3y = 7$ : $2(-2-4y) - 3y = 7 \Rightarrow -4 - 8y - 3y = 7 \Rightarrow -11y = 11 \Rightarrow y = -1$ ; $x = -2 + 4 = 2$. 2. Multiplier la 2e par 2 : $2x + 8y = -4$ ; soustraire la 1re : $11y = -11$, $y = -1$, $x = 2$. 3. Les deux droites sont sécantes en $(2,-1)$.

**C3.** 1. $u_n = 4 - 2n$. 2. $u_{12} = 4 - 24 = -20$. 3. $S = \frac{(n+1)(u_0 + u_{12})}{2} = \frac{13(4-20)}{2} = \frac{13 \times (-16)}{2} = -104$.

**C4.** 1. $v_n = 3 \times 4^n$. 2. $v_5 = 3 \times 1024 = 3072$. 3. $S = 3 \times \frac{1 - 4^6}{1-4} = 3 \times \frac{1 - 4096}{-3} = 4095$.

**C5.** 1. $w_1 = 2(5) - 3 = 7$ ; $w_2 = 2(7) - 3 = 11$ ; $w_3 = 2(11) - 3 = 19$. 2. $w_{n+1} - 3 = 2w_n - 3 - 3 = 2w_n - 6 = 2(w_n - 3)$ : géométrique de raison 2, premier terme $w_0 - 3 = 2$. 3. $w_n - 3 = 2 \times 2^n = 2^{n+1}$ ; $w_n = 3 + 2^{n+1}$ ; $\lim w_n = +\infty$.

### SECTION D

**D1.** Total 12 boules. 1. $P(R) = \frac{4}{12} = \frac{1}{3}$. 2. $P(R \cup B) = \frac{4+3}{12} = \frac{7}{12}$. 3. $P(\text{pas noire}) = 1 - \frac{5}{12} = \frac{7}{12}$.

**D2.** 1. Arbre : A avec proba 0,6 (défectueux 0,02 / bon 0,98) ; B avec proba 0,4 (défectueux 0,05 / bon 0,95). 2. $P(D) = P(A)P(D|A) + P(B)P(D|B) = 0,6 \times 0,02 + 0,4 \times 0,05 = 0,012 + 0,02 = 0,032$. 3. $P(A|D) = \frac{0,012}{0,032} = 0,375$.

**D3.** 1. Moyenne globale $= \frac{40 \times 12 + 60 \times 10}{100} = \frac{480 + 600}{100} = 10,8$. 2. Un écart-type de 2 signifie que les notes sont en moyenne à 2 points de la moyenne ; il mesure la dispersion autour de la moyenne. 3. Soit $k$ élèves à 14 : $\frac{600 + 14k}{60 + k} = 11 \Rightarrow 600 + 14k = 660 + 11k \Rightarrow 3k = 60 \Rightarrow k = 20$ élèves.

**D4.** 1. 5 tirages indépendants avec probabilité de succès $p = 0,5$ : $X \sim B(5 ; 0,5)$. 2. $P(X=3) = \binom{5}{3}(0,5)^5 = 10 \times 0,03125 = 0,3125$. 3. $E(X) = 5 \times 0,5 = 2,5$ ; $V(X) = 5 \times 0,5 \times 0,5 = 1,25$.

**D5.** 1. $P(85 \leq X \leq 115) = P(\mu \pm \sigma) \approx 0,68$. 2. $Z = \frac{X - 100}{15}$ ; pour $x = 130$, $z = \frac{30}{15} = 2$. 3. $P(X \geq 100) = 0,5$ par symétrie (100 est la moyenne).
