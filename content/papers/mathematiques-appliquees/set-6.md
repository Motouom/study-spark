## SECTION A : APPLICATIONS (intérêts, emprunts, optimisation)

**Exercice A1.** Un agriculteur place 2 500 000 FCFA à intérêts composés au taux annuel de 7,5%.

1. Calculer la valeur acquise après 5 ans (au franc près).
2. Déterminer le nombre d'années nécessaires pour tripler le capital.
3. Calculer le montant total des intérêts perçus.

**Exercice A2.** Un emprunt de 3 000 000 FCFA est remboursable par 10 annuités constantes au taux de 6% par an.

1. Calculer l'annuité constante $a$.
2. Établir le tableau d'amortissement des deux premières lignes.
3. Calculer le total des intérêts versés sur toute la durée de l'emprunt.

**Exercice A3.** Le bénéfice d'une PME est donné par $B(x) = -x^3 + 6x^2 + 15x$, où $x$ est la production en dizaines de milliers d'unités.

1. Calculer $B'(x)$.
2. Déterminer la production qui maximise le bénéfice (valeur exacte puis arrondie à l'entier).
3. Calculer le bénéfice maximal correspondant.

**Exercice A4.** Une compagnie de transport a un coût total $C(x) = 0,1x^2 + 20x + 900$ (en milliers de FCFA) pour $x$ trajets, et une recette $R(x) = 60x$.

1. Déterminer la fonction bénéfice.
2. Déterminer les quantités de rentabilité (où $B(x) = 0$).
3. Déterminer la quantité qui maximise le bénéfice.

**Exercice A5.** Une coopérative veut clôturer un enclos rectangulaire adossé à un mur (le mur forme un côté). Elle dispose de 300 m de grillage.

1. Exprimer l'aire en fonction d'une dimension $x$.
2. Déterminer les dimensions de l'aire maximale.
3. Calculer cette aire maximale.

## CORRIGÉ

### SECTION A

**A1.** 1. $V = 2\,500\,000 \times (1,075)^5$ ; $1,075^5 = 1,43563$ ; $V = 3\,589\,082$ FCFA. 2. $1,075^n = 3$ : $n = \frac{\ln 3}{\ln 1,075} = \frac{1,0986}{0,0723} = 15,19$, soit **16 ans** (arrondi à l'entier supérieur). 3. Intérêts $= V - C = 3\,589\,082 - 2\,500\,000 = 1\,089\,082$ FCFA.

**A2.** 1. $a = 3\,000\,000 \times \frac{0,06}{1-(1,06)^{-10}}$. $(1,06)^{-10} = 0,55839$ ; $a = 3\,000\,000 \times \frac{0,06}{0,44161} = 3\,000\,000 \times 0,13587 = 407\,610$ FCFA. 2. Ligne 1 : intérêt $= 3\,000\,000 \times 0,06 = 180\,000$ ; amortissement $= 407\,610 - 180\,000 = 227\,610$ ; capital restant $= 2\,772\,390$. Ligne 2 : intérêt $= 2\,772\,390 \times 0,06 = 166\,343,4$ ; amortissement $= 407\,610 - 166\,343,4 = 241\,266,6$ ; capital restant $= 2\,531\,123,4$. 3. Total payé $= 10 \times 407\,610 = 4\,076\,100$ ; intérêts $= 4\,076\,100 - 3\,000\,000 = 1\,076\,100$ FCFA.

**A3.** 1. $B'(x) = -3x^2 + 12x + 15$. 2. $B' = 0 \Leftrightarrow -3x^2 + 12x + 15 = 0 \Leftrightarrow x^2 - 4x - 5 = 0$ ; $\Delta = 16 + 20 = 36$ ; $x = \frac{4 \pm 6}{2}$ : $x = 5$ ou $x = -1$. On retient $x = 5$ (positif, et $B''(5) = -6(5)+12 = -18 < 0$ : maximum). 3. $B(5) = -125 + 150 + 75 = 100$ (en dizaines de milliers de FCFA, soit 1 000 000 FCFA).

**A4.** 1. $B(x) = 60x - (0,1x^2 + 20x + 900) = -0,1x^2 + 40x - 900$. 2. $B = 0 \Leftrightarrow 0,1x^2 - 40x + 900 = 0 \Leftrightarrow x^2 - 400x + 9000 = 0$ ; $\Delta = 160000 - 36000 = 124000$ ; $x = \frac{400 \pm \sqrt{124000}}{2} = \frac{400 \pm 352,14}{2}$ : $x_1 = 23,9$ et $x_2 = 376,1$. Rentable entre environ 24 et 376 trajets. 3. $B'(x) = -0,2x + 40 = 0 \Leftrightarrow x = 200$ ; bénéfice maximal $B(200) = -0,1(40000) + 8000 - 900 = -4000 + 7100 = 3100$ (milliers de FCFA, soit 3 100 000 FCFA).

**A5.** 1. Soit $x$ la largeur et $y$ la longueur ; grillage : $2x + y = 300$ donc $y = 300 - 2x$ ; aire $A(x) = x(300 - 2x) = 300x - 2x^2$. 2. $A'(x) = 300 - 4x = 0 \Leftrightarrow x = 75$ ; $y = 300 - 150 = 150$. 3. Aire maximale $= 75 \times 150 = 11\,250$ m².

### SECTION B

**B1.** 1. $f'(x) = 3x^2 - 6x - 9 = 3(x^2 - 2x - 3) = 3(x-3)(x+1)$. 2. $f' > 0$ sur $]-\infty,-1[ \cup ]3,+\infty[$, $f' < 0$ sur $]-1,3[$ : croissante puis décroissante puis croissante. 3. $f(-1) = -1 - 3 + 9 + 5 = 10$ (maximum local) ; $f(3) = 27 - 27 - 27 + 5 = -22$ (minimum local).

**B2.** 1. Définie sur $\mathbb{R}\setminus\{-2\}$. 2. $f(x) = x - 2 + \frac{3}{x+2}$ (division : $(x^2-1) = (x-2)(x+2) + 3$). 3. $f'(x) = 1 - \frac{3}{(x+2)^2}$ ; $f' = 0 \Leftrightarrow (x+2)^2 = 3 \Leftrightarrow x = -2 \pm \sqrt{3}$. La droite $y = x - 2$ est asymptote oblique (car $\frac{3}{x+2} \to 0$).

**B3.** 1. $f'(x) = 2x e^x + (x^2+1) e^x = (x^2 + 2x + 1)e^x = (x+1)^2 e^x$. 2. $(x+1)^2 \geq 0$ et $e^x > 0$ donc $f' \geq 0$ : $f$ est croissante sur $\mathbb{R}$ (stationnaire en $x=-1$). 3. $\lim_{x\to-\infty} (x^2+1)e^x = 0$ (croissance de $e^x$ dominée) ; $\lim_{x\to+\infty} f = +\infty$.

**B4.** 1. $f$ est continue et positive sur $[1,3]$ (dénominateur non nul et positif). 2. $\int_1^3 \frac{1}{x} dx = [\ln x]_1^3 = \ln 3 - \ln 1 = \ln 3$. 3. Valeur moyenne $= \frac{1}{3-1}\int_1^3 \frac{1}{x} dx = \frac{\ln 3}{2}$.

**B5.** 1. Définie sur $[0,+\infty[$ ; $f'(x) = \frac{1}{2\sqrt{x}}$ (pour $x > 0$). 2. $f(4) = 2$, $f'(4) = \frac{1}{4}$ ; tangente $y = 2 + \frac{1}{4}(x-4) = \frac{1}{4}x + 1$. 3. $\int_1^4 \sqrt{x} dx = \left[\frac{2}{3}x^{3/2}\right]_1^4 = \frac{2}{3}(4^{3/2} - 1) = \frac{2}{3}(8 - 1) = \frac{14}{3}$.

### SECTION C

**C1.** 1. $\Delta = 4 + 60 = 64$ ; $x = \frac{2 \pm 8}{2}$ : $x = 5$ et $x = -3$. 2. $X^2 - 5X + 4 = 0$, $\Delta = 25 - 16 = 9$ ; $X = 1$ ou $X = 4$ ; donc $x = \pm 1$ ou $x = \pm 2$. 3. $2x^2 - 4x + 2 = 2(x-1)^2 = 0$ : $x = 1$ (double).

**C2.** 1. De $5x - y = 7$, $y = 5x - 7$ ; dans $3x + 2y = 12$ : $3x + 2(5x-7) = 12 \Rightarrow 3x + 10x - 14 = 12 \Rightarrow 13x = 26 \Rightarrow x = 2$ ; $y = 10 - 7 = 3$. 2. Multiplier la 2e par 2 : $10x - 2y = 14$ ; additionner avec $3x + 2y = 12$ : $13x = 26$, $x = 2$, $y = 3$. 3. Vérification : $3(2) + 2(3) = 12$ ✓ et $5(2) - 3 = 7$ ✓.

**C3.** 1. $u_8 - u_3 = 29 - 14 = 15 = 5r$ donc $r = 3$ ; $u_3 = u_0 + 3r = u_0 + 9 = 14$ donc $u_0 = 5$. 2. $u_n = 5 + 3n$. 3. $S = \frac{11(u_0 + u_{10})}{2}$ ; $u_{10} = 5 + 30 = 35$ ; $S = \frac{11(5+35)}{2} = \frac{11 \times 40}{2} = 220$.

**C4.** 1. $v_5 = v_2 q^3$ : $96 = 12 q^3 \Rightarrow q^3 = 8 \Rightarrow q = 2$ ; $v_2 = v_0 q^2 = 4v_0 = 12 \Rightarrow v_0 = 3$. 2. $v_n = 3 \times 2^n$. 3. $S_7 = 3 \times \frac{1 - 2^8}{1-2} = 3 \times \frac{1 - 256}{-1} = 765$.

**C5.** 1. $u_1 = 3$, $u_2 = 4,5$, $u_3 = 5,25$. 2. $u_{n+1} - 6 = \frac{1}{2}u_n + 3 - 6 = \frac{1}{2}u_n - 3 = \frac{1}{2}(u_n - 6)$ : géométrique de raison $\frac{1}{2}$, premier terme $u_0 - 6 = -6$. 3. $u_n - 6 = -6 \times (\frac{1}{2})^n$ ; $u_n = 6 - 6 \times (\frac{1}{2})^n$ ; $\lim u_n = 6$.

### SECTION D

**D1.** 1. $P(2 \text{ as}) = \frac{4}{32} \times \frac{3}{31} = \frac{12}{992} = \frac{3}{248}$. 2. $P(\text{même couleur}) = \frac{8}{32} \times \frac{7}{31} = \frac{56}{992} = \frac{7}{124}$. 3. $P(\text{au moins un as}) = 1 - P(\text{aucun as}) = 1 - \frac{28}{32} \times \frac{27}{31} = 1 - \frac{756}{992} = \frac{236}{992} = \frac{59}{248}$.

**D2.** 1. $E(X) = 12 \times 0,3 = 3,6$ ; $V(X) = 12 \times 0,3 \times 0,7 = 2,52$. 2. $P(X=2) = \binom{12}{2}(0,3)^2(0,7)^{10} = 66 \times 0,09 \times 0,02825 = 0,1678$. 3. $P(X \leq 1) = P(X=0) + P(X=1) = (0,7)^{12} + 12(0,3)(0,7)^{11} = 0,0138 + 0,0712 = 0,085$.

**D3.** 1. Moyenne $= \frac{100+120+150+180+250}{5} = \frac{800}{5} = 160$ milliers. 2. Variance $= \frac{(100-160)^2+(120-160)^2+(150-160)^2+(180-160)^2+(250-160)^2}{5} = \frac{3600+1600+100+400+8100}{5} = \frac{13800}{5} = 2760$ ; écart-type $= \sqrt{2760} \approx 52,54$ milliers. 3. Médiane $= 150$ (3e valeur) ; elle est inférieure à la moyenne (160) car le salaire élevé (250) tire la moyenne vers le haut.

**D4.** 1. $P(A) \times P(B) = 0,6 \times 0,4 = 0,24 = P(A \cap B)$ : A et B sont indépendants. 2. $P(A \cup B) = 0,6 + 0,4 - 0,24 = 0,76$. 3. $P(B|A) = \frac{0,24}{0,6} = 0,4 = P(B)$ ; $P(A|B) = \frac{0,24}{0,4} = 0,6 = P(A)$, cohérent avec l'indépendance.

**D5.** 1. $P(54 \leq X \leq 86) = P(\mu \pm 2\sigma) \approx 0,95$ (règle empirique, $2\sigma = 16$). 2. $Z = \frac{X - 70}{8}$ ; pour $x = 78$, $z = 1$. 3. $P(X \leq 70) = 0,5$ par symétrie.
