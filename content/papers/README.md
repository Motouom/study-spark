Use `manifest.csv` to track subject, level, class, series, title, and path when uploading through the admin panel.

These papers are original StudySpark drafts aligned to Cameroon GCE-style structural practice. They should be reviewed by a qualified subject teacher before high-stakes publication.

## Content Review Register

Before a paper is published, add a row to the content review register described in `../../docs/content-quality-sourcing.md`.

`manifest.csv` is only an upload manifest. It does not prove source, permission, reviewer, review date, or version. Use `review-register.example.csv` as the minimum review-register shape until those fields are enforced in the database.

If content is copied from, adapted from, or based on a third-party source, do not publish it until the source and permission status are documented.
