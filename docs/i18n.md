# StudySpark i18n Guide

StudySpark uses a lightweight dictionary-based i18n layer for the learner interface.

## Files

- `src/lib/i18n.tsx` owns locale detection, persistence, fallback logic, and dictionaries.
- `src/components/LanguageSwitcher.tsx` provides the shared manual language selector.

## Locale Rules

- Supported locales are `en` and `fr`.
- The selected locale is saved in `localStorage` under `studyspark.locale`.
- If no saved locale exists, the browser language is used.
- When a signed-in learner profile loads, `profile.language` syncs the interface language.
- Missing French translations fall back to English instead of breaking the route.

## Adding A String

1. Add the English key to `en` in `src/lib/i18n.tsx`.
2. Add the French value to `fr` when available.
3. Use `const { t } = useI18n()` inside the component.
4. Render `t("your.key")` instead of hard-coded interface copy.

Keep keys grouped by surface, for example `dashboard.*`, `settings.*`, and `common.*`.

## Content Versus Interface

This layer translates interface chrome, labels, buttons, and empty states. Study content such as
paper titles, course markdown, and cheatsheet bodies stays content-driven from Supabase so English
and French curriculum material can be reviewed and published independently.
